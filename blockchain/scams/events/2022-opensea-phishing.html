区块链诈骗与骗局

总览　/　2022 年　/　钓鱼与授权盗币

OpenSea 合约迁移期的签名钓鱼

2022 年 2 月 19 日是星期六。前一天，OpenSea 刚开始让用户把挂单迁移到新的 Wyvern 合约。当晚美东时间 5 点到 8 点，一批 OpenSea 用户的 NFT 被转走，PeckShield 数出 254 枚，含 Bored Ape Yacht Club、Azuki、Doodles 等，外界估计约值 170 万美元。受害者没有泄露私钥，也没有发出交易，只在钱包里签了一条看不懂的消息。按 Check Point 的分析，骗子仿照 OpenSea 的迁移邮件发了钓鱼邮件，受害者签下的是一张不收钱就把 NFT 卖出的 Wyvern 订单。OpenSea 先说 32 人签了恶意内容，后改为 17 人有损失。到 2026 年 11 月，本站没有查到起诉记录。

概要

这一案是较早出名的链下签名钓鱼。受害者签的东西不上链，也不花 gas，钱包里显示的只是一串十六进制哈希。这串哈希背后是一张 Wyvern 交易协议的卖单，签了名就等于同意按单上的条件出售。骗子把单上的交易目标换成了自己的合约，价格填 0，再自己补上一张买单，交给 OpenSea 用的交易合约撮合，受害者的 NFT 就转到了骗子名下[4][6][8]。The Verge 打了个比方：受害者签的是一张空白支票，骗子拿到以后自己填完了剩下的部分[6]。

OpenSea 2 月 18 日宣布升级合约，要求有挂单的用户在一周内迁移，还说会发邮件提醒[1]。第二天晚上，被盗开始[6]。CEO Devin Finzer 说这是钓鱼攻击，和 OpenSea 网站无关，最初统计 32 名用户签了攻击者的恶意内容[2][5]；之后改为 17 人有损失，另 15 人和攻击者交互过但没丢东西[6][9]。钓鱼从哪里来，各方说法不一：PeckShield 和 Check Point 认为是冒充 OpenSea 迁移通知的钓鱼邮件[7][8]，OpenSea 当时说不知道钓鱼发生在哪里，只排除了自己的网站、正版邮件和迁移工具[4]。

骗子把一部分 NFT 在 LooksRare、Rarible 等平台卖掉，收款地址被 Etherscan 标为 Fake_Phishing5169，一度持有约 641 ETH[3][4]。Finzer 说部分被盗的 NFT 已被退回[5]；对手平台 Mintable 买到三枚被盗的 Azuki，表示要还给原主[11]。到 2026 年 11 月，本站没有查到针对这一案的起诉、逮捕或制裁的公开报道。

背景

OpenSea 和 Wyvern

2022 年初，OpenSea 是最大的 NFT 交易市场，The Verge 写它在最近一轮融资里估值 130 亿美元[6]。它的挂单和成交建在开源的 Project Wyvern 协议上。Check Point 的报告和 Protofire 为 OpenSea 交易合约做的索引都指向同一个以太坊地址 0x7be8076f4ea4a4ad08075c2508e481d6c946d12b[8][17]。公开的 Wyvern 源码把这一版标为 2.2[15]，Finzer 把新合约称为 Wyvern 2.3[4]。

在 OpenSea 上挂单不花 gas，原因是挂单本身不上链。卖家只是签一张订单，订单和签名存在 OpenSea 的服务器上。有人来买时才发交易：买方把卖家签过的卖单和自己的买单一起交给交易合约，合约核对两张单能对上，再一次性完成付款和转移[15]。Business Insider 引 Wyvern 官网的说明：订单必须由挂单人授权，授权有三种方式，签名、事先批准和撮合时批准[9]。

NFT 不是由交易合约直接拿走的。每个在 OpenSea 卖过东西的用户都有一个自己的代理合约 AuthenticatedProxy，源码注释说它“代表用户持有对资产的访问权，并在特定条件下执行调用”[16]。用户第一次出售某个合集时，要先授权这个代理转移该合集的 NFT。成交时，交易合约让卖家的代理去执行转移。所以 Finzer 事后建议担心的用户撤销对自己 NFT 合集的授权[7]。

一个月前的旧挂单问题

这次合约升级是为了解决另一个问题，两件事容易混在一起。2022 年 1 月，有人发现 OpenSea 上的旧挂单仍然有效：卖家把 NFT 转出钱包再转回来，以为挂单已经失效，其实还能按当初的低价成交。1 月 24 日前后，一名买家用这个办法低价买进多枚 NFT 再高价卖出，OpenSea 后来向受损用户赔付约 180 万美元[13][11]。那一次卖家没有签新的东西，签名是很久以前挂单时留下的，本站不把它算作诈骗。

2 月 18 日的迁移通知

2 月 18 日（周五）美东时间下午 3 点，OpenSea 开放挂单迁移。博客写道，升级会让旧的失效挂单过期，支持一笔低成本交易批量取消，并带来“描述更清楚的签名”；用户有一周时间迁移，2 月 25 日下午 2 点没迁移的挂单过期，期间会发推文和邮件提醒[1]。OpenSea 维护的 wyvern-js 库在 2 月 4 日已把主网交易合约地址从 0x7be8…d12b 改为 0x7f26…38e5[18]。

Cointelegraph 指出，一周的期限和“不迁移就过期”的说法给了骗子机会[7]。用户刚收到真的迁移邮件，再收到一封格式一样的邮件，很难分辨。

为什么算诈骗

本站按转账是谁签的来分：受害者自己签的转账和授权算诈骗。本案受害者的私钥没有泄露，每一笔被盗都有受害者本人的有效签名。链上调查者 Neso 对 The Verge 说，他检查了每一笔交易，“都有丢了 NFT 的人的有效签名”[6]。当时的媒体多用“黑客”“攻击”这类词，指的是同一件事。

骗术怎样运作

按 Check Point 的分析，整个过程分两半：受害者在钓鱼网站上签名，这一步不上链；骗子拿着签名，通过自己的合约调用 OpenSea 交易合约的 atomicMatch_，合约核对签名有效，就让受害者的代理把 NFT 转给骗子[8]。Neso 的描述是：受害者签的是半张有效的 Wyvern 订单，单上除了交易目标（骗子的合约）和调用数据，几乎什么都没填；另一半由骗子自己签[4]。

一张 Wyvern 订单里有什么

Wyvern 的订单是一个结构体，二十来个字段。和本案有关的是这几项：挂单人 maker、买卖方向 side、交易目标 target、调用方式 howToCall、调用数据 calldata、价格 basePrice[15]。正常的卖单里，target 是 NFT 合约，calldata 是“把这枚 NFT 转给买家”，价格是卖家开的价。

// ProjectWyvern/wyvern-ethereum，contracts/exchange/ExchangeCore.sol（节选）
struct Order {
    address exchange;      // 交易合约地址
    address maker;         // 挂单人，即签名的人
    address taker;         // 指定的对手方，0 表示任何人
    ...
    SaleKindInterface.Side side;           // 买或卖
    address target;                        // 代理要调用的合约
    AuthenticatedProxy.HowToCall howToCall; // Call 或 DelegateCall
    bytes calldata;                        // 调用数据
    bytes replacementPattern;              // 允许对方改写哪些字节
    ...
    address paymentToken;  // 付款币种，0 表示 ETH
    uint basePrice;        // 价格
    ...
    uint expirationTime;   // 过期时间，0 表示永不过期
    uint salt;
}

出处：ProjectWyvern/wyvern-ethereum，commit bfca101（2018-06-12），contracts/exchange/ExchangeCore.sol，节选，省略号为本站所加[15]。同一提交的 WyvernExchange.sol 写明版本为 2.2。中文注释为本站所加。

签的是一串哈希

挂单人签的是订单哈希加上以太坊的标准消息前缀，订单的各个字段并不出现在签名请求里。合约验证时用 ecrecover 从签名里恢复出地址，只要等于 maker，订单就算授权过[15]：

// 同一文件（节选）
function hashToSign(Order memory order) internal pure returns (bytes32) {
    return keccak256("\x19Ethereum Signed Message:\n32", hashOrder(order));
}

function validateOrder(bytes32 hash, Order memory order, Sig memory sig) internal view returns (bool) {
    ...
    if (cancelledOrFinalized[hash]) { return false; }  // 已取消或已成交
    if (approvedOrders[hash]) { return true; }          // 事先在链上批准过
    if (ecrecover(hash, sig.v, sig.r, sig.s) == order.maker) {
        return true;                                    // 签名者就是挂单人
    }
    return false;
}

出处：同上，函数声明合并为一行，省略了参数检查和注释[15]。

这就是钱包看不出危险的原因。按这种写法，钱包弹出的签名请求里只有一串 32 字节的十六进制数，看不到价格、目标合约和调用数据。OpenSea 的升级公告把“描述更清楚的签名”列为新合约的好处之一[1]，Creaton 的创始人 Alexander Klus 对 Cointelegraph 说，需要 EIP-712 这样的签名标准，人们才能看清自己在批准什么[12]。

撮合时合约核对什么

成交走 atomicMatch。它先分别验证买单和卖单（发交易的人自己的那张可以不签），再核对两张单能不能配对，然后取出卖家的代理合约，按卖单上的 target、howToCall、calldata 执行调用[15]：

// 同一文件，atomicMatch 和 ordersCanMatch（节选）
require(ordersCanMatch(buy, sell));
    // 一买一卖、付款币种相同、target 相同、howToCall 相同 ……
require(ArrayUtils.arrayEq(buy.calldata, sell.calldata));
OwnableDelegateProxy delegateProxy = registry.proxies(sell.maker);  // 卖家的代理
...
uint price = executeFundsTransfer(buy, sell);   // 按价格付款，价格是 0 就不付
require(proxy.proxy(sell.target, sell.howToCall, sell.calldata));  // 让卖家的代理执行

出处：同上，atomicMatch 第 688–735 行和 ordersCanMatch，节选，省略号为本站所加[15]。

合约检查的是两张单彼此一致、卖单确实是卖家签的，没有检查 target 是不是 NFT 合约，也没有检查价格是否合理。这些本来由 OpenSea 的网页在生成订单时保证。骗子自己生成订单，就绕过了网页这一层[6][8]。

代理替谁办事

代理合约的 proxy 函数只认两种调用者：代理的主人，或者注册表批准过的合约（也就是交易合约）。它按 howToCall 选择普通调用或 delegatecall[16]：

// ProjectWyvern/wyvern-ethereum，contracts/registry/AuthenticatedProxy.sol（节选）
enum HowToCall { Call, DelegateCall }

/* Delegate call could be used to atomically transfer multiple assets
   owned by the proxy contract with one order. */

function proxy(address dest, HowToCall howToCall, bytes calldata) public returns (bool result) {
    require(msg.sender == user || (!revoked && registry.contracts(msg.sender)));
    if (howToCall == HowToCall.Call) {
        result = dest.call(calldata);
    } else if (howToCall == HowToCall.DelegateCall) {
        result = dest.delegatecall(calldata);  // 以代理自己的身份运行 dest 的代码
    }
    return result;
}

出处：同上提交，contracts/registry/AuthenticatedProxy.sol，节选，函数声明合并为一行[16]。英文注释是源码原有的，意为“delegatecall 可用来在一张订单里原子地转移代理合约名下的多项资产”。

受害者早先挂单时已授权代理转移自己的 NFT。代理以自己的身份执行一段骗子写的代码，这段代码就能动用这些授权，一次转走多枚 NFT。这正是 Neso 说的“交易目标是攻击者合约”[4]，也是 Check Point 说的“一个请求就能偷走受害者的全部 NFT”[8]。

调用方式是不是 delegatecall

Neso 只说订单的交易目标是攻击者合约[4]，Check Point 只说请求经攻击者合约转发到 OpenSea 交易合约[8]，本站读过的已发表分析都没有写明 howToCall 的取值。上面的推断来自源码：用普通调用时，代理只能调用一个目标合约，而受害者授权的是代理本身，只有 delegatecall 才能让骗子的代码以代理的身份去调用各个 NFT 合约。本站不做链上取证，这一点按推断写，没有核对具体交易。

为什么只签名也会被盗

签名本身不动任何资产，所以很多人以为“没有发交易就没事”。在 Wyvern 里，签名就是授权：任何人拿到这张签过的卖单，都可以随时配上一张买单，自己发交易去撮合，gas 由他付，受害者不用再做任何事[15]。订单在过期、被取消或成交之前一直有效。受害者想作废它，要自己发一笔链上交易取消，或者撤销对代理的授权[7]。Bluzelle 的联合创始人 Neeraj Murarka 对 Cointelegraph 说，这就像签了一张空白支票，收款人本来应该是你想付的人[12]。

经过

准备

骗子提前准备了一个多月。Decrypt 查到，收款地址早在 2021 年 12 月就有了第一笔交易，还和另一个被标为 OpenSea 钓鱼的地址有往来[4]。Check Point 说，攻击用的合约在攻击前一个月创建，骗子还先对 OpenSea 交易合约试跑了一次 atomicMatch，确认办法可行[8]；BleepingComputer 转述的试跑日期是 2022 年 1 月 21 日[10]。

迁移第二天的三个小时

2 月 18 日下午 OpenSea 开放迁移[1]。Check Point 认为，骗子照搬 OpenSea 迁移邮件的格式，重新发给 OpenSea 的用户[8]；据 BleepingComputer 转述，邮件让收件人以为自己第一次确认没有成功[10]。链接打开的是钓鱼网站，网站请求的签名看起来和 OpenSea 博客里演示的迁移签名一样[8]。

2 月 19 日周六，被盗集中在美东时间下午 5 点到 8 点[6]。几个小时里出现了几百笔交易，The Verge 认为这么快的节奏说明骗子有某种共同的渠道接触到受害者[6]。社交媒体上有人呼吁 OpenSea 暂停新合约[7]，也有人传言损失达 2 亿美元，Finzer 后来否认了这个数字[5][9]。

OpenSea 的回应

当晚 OpenSea 发推说，正在调查与 OpenSea 相关智能合约的“漏洞传闻”，看来是起源于 OpenSea 网站之外的钓鱼攻击，请用户不要点 opensea.io 之外的链接[2][7]。美东晚 11 点左右，Finzer 发推：“据我们所知，这是一次钓鱼攻击……目前看来有 32 名用户签了攻击者的恶意内容，他们的部分 NFT 被盗。”[2][3]

2 月 20 日周日上午，Finzer 说公司在内外部沟通后确认是钓鱼，正在和受害者一起找出他们共同访问过的网站，还感谢了和公司直接通电话的用户[2]。他列出排除的途径：在 opensea.io 上铸造、买卖、挂单都不是攻击途径，签新的 Wyvern 2.3 合约也不是；正版 OpenSea 邮件、网站横幅、挂单迁移工具都不是[4]。他说 Neso 的分析和公司的理解一致[4]。2 月 21 日 OpenSea 发推说还没查到确切来源[10]，受害人数改为 17 人[9]。BleepingComputer 说，到 21 日攻击似乎已经停止，最后一笔在前一天[10]。

钓鱼从哪里来

说法有三种，本站并列。PeckShield 2 月 20 日推测用户是按钓鱼邮件的指示授权了“迁移”，还怀疑用户信息（含邮箱）泄露[7]。Check Point 2 月 21 日的报告明确写了钓鱼邮件和钓鱼网站[8]，BleepingComputer 据此报道，并写 OpenSea 确认钓鱼邮件来自平台外部、邮件系统没被攻破[10]。Finzer 则说“不知道钓鱼发生在哪里”，只排除了正版邮件等途径[4]；Business Insider 把这句转述成排除了“点击伪造的 OpenSea 邮件”[9]，和 Decrypt 的转述不一样，本站按 Decrypt 原文引的推文写。到 2026 年 11 月，本站没有找到 OpenSea 公布最终调查结论。四个月后，OpenSea 披露邮件服务商 Customer.io 的一名员工下载了用户邮箱[14]，那是另一起事件，没有公开材料把它和 2 月的钓鱼联系起来。

钱去了哪里

卖成 ETH

骗子拿到 NFT 后卖掉了一部分。Decrypt 写道，收款地址 Fake_Phishing5169 在 OpenSea 的对手平台 Rarible 和 LooksRare 上都有交易，2 月 20 日凌晨持有约 641 ETH，约合 170 多万美元[3][4]。Finzer 说，攻击者钱包里有卖掉部分被盗 NFT 得来的 170 万美元 ETH[5][9]。Check Point 2 月 21 日看到的数字是 200 多万美元[8]。几家说的都是这个地址某一时刻的 ETH 余额，口径不是被盗 NFT 的总价值。

退回和混币

Decrypt 注意到一些反常的转账：一名受害者的部分资产被拿走后又被退回，骗子还给他转了 50 ETH；一部分去向经过 Tornado Cash，另一部分没有[4]。Finzer 2 月 20 日说部分被盗的 NFT 已经退回[5]，Cointelegraph 3 月的文章也说黑客把一部分 NFT 还给了原主[12]。骗子为什么退回，公开报道没有解释。

流到市场上的 NFT 被别人买走。Mintable 说，它在 LooksRare 上为自己的促销活动收购 Azuki 时，买到了编号 1178、4176、1180 三枚被盗的 Azuki，决定还给原来的持有人。Mintable 的 CEO Zach Burks 说：“如果 OpenSea 不去弥补，总得有人来做。”[11]

本站没有找到链上分析机构对这批 ETH 后续去向的完整追踪，也没有查到有交易所冻结过相关资金。

受害者与规模

多少人

受害者是持有高价 NFT 的 OpenSea 用户，身份大多没有公开，本站不写能认出个人的细节。OpenSea 最初说 32 人，后来改为 17 人：另外 15 人和攻击者交互过，但没有因此丢失代币[6][9]。BleepingComputer 写的也是 17 人[10]。

估值按什么算

NFT 没有统一的价格，估值通常按合集地板价或成交价算，各家没有说明方法。170 万美元这个数，The Verge 说是 Molly White 对被盗 NFT 的估计[6]，Finzer 说的却是攻击者钱包里的 ETH[5]，两者恰好接近，口径不同。一部分 NFT 后来被退回[5][11]，净损失应低于这些数字，没有人公布过净额。本站按约 170 万美元记，并列其他说法。

被盗的是什么

各家报道提到的合集有 Bored Ape Yacht Club、Azuki、Doodles、Cool Cats 和 Decentraland[3][4][6]。这些都是 2021 年 NFT 热潮里地板价最高的一批，NFT 热潮本身见大事记的 Beeple 的 NFT 在佳士得拍出 6,935 万美元，以太坊上最早出名的 NFT 见 CryptoKitties。

追查与执法

到 2026 年 11 月，本站没有查到针对这一案的刑事起诉、逮捕、制裁或执法扣押的公开报道，骗子的身份也没有公开。OpenSea 当时说在和受害者一起调查[2]，没有公开说过向执法机构报案。

赔付

一个月前的旧挂单事件，OpenSea 用 ETH 赔了受损用户约 180 万美元[11][13]。这一次，本站没有找到 OpenSea 赔付的记录。Mintable 2 月 23 日退还三枚 Azuki 时说“如果 OpenSea 不去弥补，总得有人来做”[11]，说明至少到那时 OpenSea 没有宣布赔付。同一篇报道提到，一名在 1 月事件里丢了 Bored Ape 的用户起诉 OpenSea，索赔 100 万美元[11]，那是 1 月一案，不涉及本案。

OpenSea 后来做了什么

迁移按原计划在 2 月 25 日完成[1]。OpenSea 当时的建议是只用 opensea.io，不点站外链接，担心的用户可以撤销对 NFT 合集的授权[2][7]。2022 年 6 月邮箱泄露后，OpenSea 的安全负责人提醒用户，不要在邮件的引导下签钱包交易[14]。

怎样识别

邮件和通知
  • 平台真的在做迁移、升级时，最容易收到假通知。本案的钓鱼邮件照搬了 OpenSea 迁移邮件的格式，发在真迁移开始的第二天[1][8]。不点邮件里的链接，从书签或手动输入的网址进入平台，再看有没有要做的事。
  • “上次确认没有成功，请重新确认”“一周内不迁移就过期”，这类话术制造紧迫感[10][7]。OpenSea 的真迁移即使错过期限，也可以免费重新挂单[1]。
  • 发件人可以伪造。Murarka 对 Cointelegraph 说，邮件可以由任何人发出，却显示成别人发的[12]。
签名请求
  • 不花 gas 不等于没有风险。本案受害者一笔交易都没发，只签了一条消息[6]。签名请求在交易市场里往往就是一张订单，别人拿到后可以替你成交[15]。
  • 看不懂的签名不签。钱包里只显示一串十六进制哈希时，你无从知道价格和交易对象[15]。能显示字段的签名（EIP-712）要逐项看：价格是不是 0，交易目标是不是你认识的合约[12]。
  • 同类手法后来被做成了工具包，盗走的也不只是 NFT。签一条 Permit 或订单就丢币的例子见 Inferno Drainer、MS Drainer，签一笔交易就交出整个合约钱包的例子见 5,547 万 DAI 签名钓鱼。
放 NFT 的钱包
  • 挂单授权是长期有效的。在交易市场卖过的合集，代理一直有权转走它们[16]。不再卖的合集，撤销授权；Finzer 事后也这样建议[7]。
  • 高价 NFT 放在一个不连网站、不签任何东西的地址里，日常挂单和领空投用另一个地址。
  • 已经签了，马上撤销对代理的授权或在链上取消订单，并联系平台。本案被盗的 NFT 有一部分出现在其他市场上，被买家认出后退回[11]。
