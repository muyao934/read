区块链被盗事件编年史

总览　/　2022 年　/　跨链桥之年

Ronin 跨链桥被盗

2022 年 3 月 23 日，攻击者凑齐了 Ronin 跨链桥 9 个验证者中 5 个的签名，用两笔伪造的提现转走 173,600 枚 ETH 和 2,550 万 USDC，按被盗时的价格约 5.4 亿美元，到被发现时已超过 6 亿美元。桥合约本身没有漏洞，失守的是签名者：其中 4 个节点属于同一家公司，第 5 个来自一项早该撤销的授权。桥上没有大额流出告警，盗窃在六天后才因为一笔用户提现失败而暴露。

概要

Ronin 是 Sky Mavis 为游戏 Axie Infinity 搭建的以太坊侧链。资产在以太坊和 Ronin 之间往返要经过一座桥，以太坊侧的桥合约放款前，核心的检查只有一项：这笔提现是否带有足够多验证者的签名。当时的门槛是 9 个验证者中的 5 个，其中 4 个节点由 Sky Mavis 自己运营。

据 The Block 援引知情人士的报道，攻击者冒充一家并不存在的公司，通过 LinkedIn 联系 Sky Mavis 的一名高级工程师，经过几轮“面试”后发去一份 PDF 格式的 offer，文件里带有间谍软件[5]。Sky Mavis 官方只确认一名员工被鱼叉式钓鱼攻破，攻击者由此进入公司的 IT 系统，控制了 4 个验证者节点[2]。第 5 个签名来自 Axie DAO 的验证者：2021 年 11 月用户量暴增，Sky Mavis 请 Axie DAO 帮忙分发免 gas 交易，Axie DAO 把 Sky Mavis 加进白名单，允许它代为签署交易；12 月这项安排停止了，白名单却一直没撤[1]。

3 月 23 日，攻击者用这 5 个签名从桥合约提走 173,600 枚 ETH 和 2,550 万 USDC。六天后，一名用户提现 5,000 ETH 失败，Sky Mavis 才发现被盗[1]。4 月 14 日，FBI 认定朝鲜的 Lazarus Group 和 APT38 对此负责，美国财政部同日制裁了收款地址[3][4]。Sky Mavis 用自有资金补足了用户资产，桥在 6 月 28 日加上熔断分级和每日限额后重新开放[14][15]。2022 年 9 月，超过 3,000 万美元的赃款被扣押[8]；Axie DAO 金库被盗的 5.6 万枚 ETH 没有得到补偿。

背景

Axie Infinity 是一款基于 NFT 的“边玩边赚”游戏，玩家用名为 Axie 的宠物对战，赚取 SLP 等代币。2022 年 4 月 Axie 公布的数据是：月活跃玩家 220 万，持有 Axie 的地址 260 万[14]。为了解决在以太坊主网上开发 Axie 时遇到的问题，Sky Mavis 自建了侧链 Ronin，把游戏内交易和交易市场搬了上去[15]。

Ronin 不是由大量节点竞争出块的公链，而是由少数获准的验证者运行的权威证明（Proof of Authority）链。rekt.news 的评论是，为了最大化吞吐量，去中心化和去信任被放在了次要位置[7]。资产跨链靠一座桥：以太坊侧的合约锁住用户存入的 ETH、USDC 等资产，Ronin 侧发行对应的代币；用户要把资产提回以太坊，先在 Ronin 上发起提现，拿到验证者的签名，再到以太坊侧的合约领取。

这座桥由 Ronin 的验证者把守。按 Sky Mavis 事后的说明，当时链上共有 9 个验证者节点，确认一笔存款或提现需要其中 5 个签名；门槛定得低，是因为有些节点跟不上链的进度，或者卡在同步状态[1]。

问题在于这 9 个节点并不独立。Sky Mavis 自己运营其中 4 个，离 5 个只差一个。差的这一个来自 2021 年底那次临时安排：Axie DAO 允许 Sky Mavis 代它签署交易，安排在 12 月停止后，白名单权限没有收回[1]。从那时起，只要攻破 Sky Mavis 的系统，就能同时拿到 5 个签名。

按 Sky Mavis 的说法，被盗的 ETH 中有 5.6 万枚属于 Axie DAO 的社区金库[15]。

攻击原理

这次事件里，桥合约没有漏洞，它完全按设计运行。出问题的是这个设计所依赖的信任假设：它假定拿得出足够多验证者签名的提现就是真的。先看一次正常的提现和攻击者的伪造提现有什么不同。

正常提现

用户在 Ronin 侧调用网关合约的 withdrawERC20For，代币被转进网关，合约按顺序分配一个提现编号并发出 TokenWithdrew 事件。验证者看到事件后各自签名，通过 submitWithdrawalSignatures 提交到 Ronin。用户收集签名，到以太坊侧领钱[11]。

伪造提现

Ronin 侧什么都没发生。攻击者自己编了提现编号、收款人、代币和数量，用掌握的 5 个验证者身份对这条消息签名，直接拿到以太坊侧领钱。以太坊上的合约看不到 Ronin 的状态，只能核对签名。

下面是攻击前最后一次修改（2022 年 1 月 13 日）时，以太坊侧网关合约中提现和验签的代码[11]。英文注释是原有的，中文注释是本站加的：

// MainchainGatewayManager.sol（commit 8992526），以太坊侧网关合约
function withdrawERC20For(
  uint256 _withdrawalId,
  address _user,
  address _token,
  uint256 _amount,
  bytes memory _signatures
)
  public
  whenNotPaused
  onlyMappedToken(_token, 20)
{
  // 被签名的消息只有四个字段：编号、收款人、代币、数量
  bytes32 _hash = keccak256(
    abi.encodePacked("withdrawERC20", _withdrawalId, _user, _token, _amount)
  );

  require(verifySignatures(_hash, _signatures));   // 放款的唯一实质条件

  if (_token == registry.getContract(registry.WETH_TOKEN())) {
    _withdrawETHFor(_user, _amount);              // WETH 解包成 ETH 后直接转给 _user
  } else {
    // ……（余额不足时尝试 mint，随后 transfer 给 _user）……
  }

  // 只要求这个编号以前没用过，不要求它在 Ronin 上真实存在
  _insertWithdrawalEntry(_withdrawalId, _user, _token, _amount);
}

function verifySignatures(bytes32 _hash, bytes memory _signatures) public view returns (bool) {
  // 每个签名 66 字节：签名模式 1 字节 + r 32 + s 32 + v 1
  uint256 _signatureCount = _signatures.length.div(66);

  Validator _validator = Validator(registry.getContract(registry.VALIDATOR()));
  uint256 _validatorCount = 0;
  address _lastSigner = address(0);

  for (uint256 i = 0; i < _signatureCount; i++) {
    address _signer = _hash.recover(_signatures, i.mul(66));
    if (_validator.isValidator(_signer)) {
      _validatorCount++;
    }
    // Prevent duplication of signatures
    require(_signer > _lastSigner);   // 签名者地址必须严格递增，防止同一签名重复计数
    _lastSigner = _signer;
  }

  return _validator.checkThreshold(_validatorCount);
}

来源：axieinfinity/ronin-smart-contracts 仓库，commit 899252692d，contracts/chain/mainchain/MainchainGatewayManager.sol 第 192–236 行与第 292–317 行。原文 keccak256 的每个参数各占一行，这里压缩为一行；ERC-20 分支的 mint 与 transfer 从略。

门槛由验证者合约计算。门槛和验证者名单都能由一个 admin 地址修改：

// Validator.sol（commit 8992526），第 48–54 行
function checkThreshold(uint256 _voteCount)
  public
  view
  returns (bool)
{
  return _voteCount.mul(denom) >= num.mul(validatorCount);   // 攻击时 num = 5，denom = 9
}

// MainchainValidator.sol（commit 8992526），第 21–33 行
function addValidators(address[] calldata _validators) external onlyAdmin { /* … */ }
function removeValidator(address _validator) external onlyAdmin { /* … */ }
function updateQuorum(uint256 _numerator, uint256 _denominator) external onlyAdmin { /* … */ }

来源：同上，contracts/chain/common/Validator.sol 与 contracts/chain/mainchain/MainchainValidator.sol。三个管理函数的函数体从略。

按官方说明的 9 个验证者、5 个签名代进去：validatorCount = 9，num = 5，denom = 9，条件变成 _voteCount × 9 ≥ 45，也就是 5 个有效签名就够[1]。攻击者拿到的正是 5 个验证者的签名，合约没有任何理由拒绝它们。

提现编号也拦不住伪造的提现。从代码看，以太坊侧只检查编号有没有被用过，不核对这笔提现在 Ronin 上是否真的发生过；伪造的提现只要用没被用过的编号，就能通过这项检查[11]。

第 5 个签名从哪里来

Sky Mavis 的 4 个节点由攻击者直接控制，因为他们已经进入了 Sky Mavis 的系统。官方对第 5 个签名的解释是：攻击者在 Sky Mavis 的免 gas RPC 节点里找到一个“后门”，用它拿到了 Axie DAO 验证者的签名；后门之所以存在，是因为 2021 年 11 月 Axie DAO 把 Sky Mavis 加进白名单，12 月停用时没有撤销[1][2]。官方没有公开这个 RPC 节点具体接受什么请求，也没有解释 Axie DAO 的节点为什么会给一笔根本不存在的提现签名。

“私钥被盗”还是“签名被代签”

Sky Mavis 的公告正文说攻击者通过白名单“拿到了 Axie DAO 验证者的签名”，同一篇的问答部分又说“5 把验证者私钥被盗，4 把属于 Sky Mavis，1 把属于 Axie DAO”[1]。两种说法对应的攻击路径不同，本页没有找到官方对这处出入的解释。

为什么六天没人发现

旧桥合约没有单笔上限，没有每日限额，也没有大额延迟到账。Sky Mavis 在 post-mortem 里承认，当时没有任何系统监控桥上的大额流出[2]。六天后，一名用户提现 5,000 ETH 失败，问题才暴露出来[1]。

攻击过程

入侵阶段的细节来自两处：Sky Mavis 的 post-mortem 和 The Block 援引两名知情人士的报道。官方没有公布入侵发生的日期。链上阶段依据 Ronin 的公告和 Elliptic、Chainalysis 的分析[1][6][8]。

  1. 虚假招聘据 The Block 报道，冒充一家并不存在的公司的人通过 LinkedIn 接触 Sky Mavis 的一名高级工程师，经过几轮面试后发出 offer。offer 是一份 PDF，工程师下载后，间谍软件进入了 Ronin 的系统[5]。Sky Mavis 拒绝评论具体手法，只在 post-mortem 里说员工长期在各种社交渠道遭受高级鱼叉式钓鱼，其中一人被攻破，此人已离职[2]。
  2. 从员工电脑到验证者节点攻击者以这名员工的权限为跳板，渗透进 Sky Mavis 的 IT 基础设施，拿到了验证者节点的访问权[2]。4 个 Sky Mavis 节点的签名能力从此落入攻击者手中。
  3. 拿到第 5 个签名攻击者利用 Sky Mavis 免 gas RPC 节点上没有撤销的白名单，取得了 Axie DAO 验证者的签名[1]。
  4. 伪造提现攻击者用拿到的 5 个签名伪造了两笔提现，一笔 173,600 ETH，一笔 2,550 万 USDC[1]。收款地址 0x098b716b8aaf21512996dc57eb0615e2383e2f96 列在 Ronin 的公告里，后来被 Etherscan 标为 Ronin Bridge Exploiter，并被 OFAC 列入制裁名单[1][12][4]。
  5. 提交到以太坊3 月 23 日，两笔提现被提交给以太坊侧的桥合约。合约核对的是签名是否有效、数量够不够门槛，两项都满足就放款[1][11]。
  6. 换掉可冻结的资产USDC 可以被发行方冻结。Elliptic 观察到，攻击者先通过 DEX 把 USDC 换成 ETH，避开了中心化交易所的 AML 和 KYC 检查[6]。

两笔交易的哈希是 0xc28fad5e8d5e0ce6a2eaf67b6687be5d58113e16be590824d6cfa1a94467d0b7 和 0xed2c72ef1a552ddaec6dd1f5cddf0b59a8f37f82bdda5257d9c7c37db7bb9b08，见 Ronin 公告所附链接[1]。

资金去向

攻击者的主地址在 Etherscan 上被标为 Ronin Bridge Exploiter，并带有 OFAC 制裁标记[12]。Chainalysis 把 Lazarus Group 处理这笔钱的流程概括为五步，整个过程用到了 12,000 多个地址[8]：

  1. 主地址173,600 ETH，加上 2,550 万 USDC 换成的 ETH
  2. 中间钱包按批次转出，PeckShield 观察到每两三天约 3,000 ETH
  3. Tornado CashETH 分批混币，是最主要的通道
  4. 换成 BTC 后兑现BTC 再分批混币，其中超过 2,050 万美元经过 Blender.io；最后存入兑法币的服务，接收方大多未公开

PeckShield 的观察见 The Record 的报道[13]，Blender.io 的数字来自美国财政部[9]。各机构当时公布的洗钱进度：PeckShield 称到 4 月 9 日约 7.5% 已被洗出，钱包里还有约 159,710 ETH[13]；Elliptic 称到 4 月 14 日已有 18% 被洗出，原地址剩约 4.33 亿美元[6]。

Elliptic 在 4 月 14 日的拆分是：攻击者先把约 1,670 万美元的 ETH 转进三家中心化交易所，这在 DeFi 攻击里不常见，但在 Lazarus 过去的案子里出现过；交易所公开表示会配合执法后，攻击者转向 Tornado Cash，截至当时送进去约 8,030 万美元，另有约 970 万美元停在中间钱包，等着被混币[6]。rekt.news 提到较早转出的 6,250 ETH 有一部分进了 FTX 和 Crypto.com[7]。

美国财政部 8 月制裁 Tornado Cash 时称，它洗过的资金中包括 Lazarus Group 在“迄今已知最大的虚拟货币盗窃案”中所盗的超过 4.55 亿美元[10]，Chainalysis 的文章明确把这笔钱对应到本案[8]。Tornado Cash 被制裁后，Chainalysis 观察到 Lazarus 转而用跨链桥和 DeFi 服务在币种之间来回跳转，例如把 ETH 跨到 BNB Chain 换成 USDD，再跨到 BitTorrent Chain[8]。

追回了多少

2022 年 9 月 8 日，Chainalysis 宣布在执法部门和行业机构的协助下，超过 3,000 万美元的赃款被扣押，按被盗与扣押时的价差折算约占总额的 10%，并称这是朝鲜黑客所盗加密资产第一次被扣押。同一篇文章也说，大部分资金仍在黑客控制的钱包里[8]。

此后的公开信息很少。2025 年 8 月 Axie Infinity 的治理公告提到，预计约 600 万 USDC 和“约 4,000 万”的其他资产会作为本案的追回款陆续进入社区金库[25]。公告没有说明这些资产来自哪次扣押或司法程序，“约 4,000 万”也没有写明单位。

影响

损失金额的几种口径

被盗的数量没有争议，金额却有好几个说法，差别主要来自按哪一天的 ETH 价格折算。Elliptic 的标题写作 5.4 亿美元，正文说被发现时这笔钱价值超过 6.15 亿美元[6]。FBI 的说法是 6.2 亿美元[3]，rekt.news 和不少媒体写约 6.24 亿至 6.25 亿美元[7][16]。本页顶部采用的 约 6.24 亿美元 属于后一类，更接近发现时的价值。

排名也随口径变化。美国财政部 2022 年称它是“迄今最大的虚拟货币盗窃案”[10]；Elliptic 按被盗时价值把它列为史上第二大加密货币盗窃[6]。如果按被盗时价值比较，2021 年的 Poly Network 约 6.11 亿美元更高，那笔钱后来全数归还。

对 Axie 玩家

官方桥从 3 月 29 日关闭到 6 月 28 日，整整三个月。期间 Ronin 上的 AXS、RON、SLP 不受影响，但用户没法通过官方桥存取 ETH 和 USDC[1]。Binance 为 Axie 用户提供了 wETH 的充提通道，到 6 月共有 4.6 万枚 wETH 经 Binance 转出，所需的 ETH 流动性来自 Axie Infinity 的资产负债表和创始团队的资金[15]。

朝鲜与混币器制裁

案发三周后，FBI 公开把这起盗窃归到朝鲜名下，并表示会与财政部一起继续揭露朝鲜用网络犯罪和加密货币盗窃为政权创收的行为[3]。本案的洗钱路径随后出现在美国财政部的两项制裁里：2022 年 5 月制裁 Blender.io，这是财政部第一次制裁混币器[9]；8 月制裁 Tornado Cash，公告列举的第一个案例就是本案[10][8]。制裁的经过和后来的诉讼，见大事记的OFAC 制裁 Tornado Cash。

后续处置

最初几天的止血

3 月 29 日，Sky Mavis 把签名门槛从 5/9 提到 8/9[1]。rekt.news 当时就指出，这项改动比官方公告早了近 11 小时[7]。随后桥和 Katana DEX 暂停，节点迁到与旧基础设施完全隔离的新环境[1]。3 月 31 日，原 Sky Mavis 的验证者全部更换[1]。

这些操作本身暴露了另一个单点。从合约代码看，改门槛和增删验证者都只需要 admin 一个地址[11]。它让 Sky Mavis 能在几小时内堵上口子；反过来，谁拿到这把钥匙，谁就能把门槛改低，或者把自己的地址加进验证者名单。

谁来填这个窟窿

桥重新开放时，Ronin 公布了 173,600 ETH 和 2,550 万 USDC 缺口的处理方式[15]：

部分数量处理方式
Axie DAO 金库的份额56,000 ETH不补足，留给执法追回；两年内追不回，由 Axie DAO 投票决定下一步
经 Binance 提走的部分46,000 ETH用户在 Binance 把 wETH 换成 ETH，ETH 来自 Axie Infinity 的资产负债表和创始团队；Binance 收到的 wETH 被转进 Ronin 上的销毁地址
剩余负债71,600 ETH + 2,550 万 USDC由 Sky Mavis 全额补足，Ronin 上的 wETH 和 USDC 恢复与以太坊侧 1:1 足额

4 月 6 日宣布的 1.5 亿美元融资由 Binance 领投，Animoca Brands、a16z、Dialectic、Paradigm、Accel 参与，当时说与 Sky Mavis 和 Axie 的自有资金一起用于赔付[14]。2023 年 7 月 17 日，Axie 在同一篇公告前补了一段：随着对事件了解加深，Sky Mavis 和 Axie Infinity 用公司自己的资产负债表就补足了桥，这轮融资因此大幅缩减，最终只募了 1,100 万美元[14]。“融资 1.5 亿美元赔付用户”这一流传很广的说法，需要按这段更新来理解。

Axie DAO 金库的 5.6 万枚 ETH 没有补上。本站没有找到“两年内由 DAO 投票决定”那次投票的公开记录。2025 年 8 月的治理公告称，截至 2025 年 7 月金库里约有 2,600 枚 ETH，并预计会有本案的追回款进入金库[25]。

新桥的设计

6 月 28 日开放的新桥经过一次内部审计和 Verichains、CertiK 两次外部审计，主要改了三处[15]：

  • 治理者与验证者分开。增删验证者、升级合约、改门槛这类变更，改由治理者（Governor）投票决定，同一时间只能进行一项投票。官方的比喻是：治理者像冷钱包，验证者像热钱包。
  • 熔断分级。按提现金额要求不同比例的验证者签名：一般提现 70%；100 万美元以上 90%；1,000 万美元以上 90% 加人工审核，并进入 7 天的审查期。
  • 每日限额。验证者可以设置每日提现上限，初始为 5,000 万美元，每天 00:00（UTC）重置；第三档提现需要管理员操作，不计入每日限额。

拿 3 月 23 日的第 1 笔交易套这套规则：173,600 ETH 当时约值 5.1 亿美元，落在第三档，需要约 90% 的验证者签名并经过人工审核。攻击者手里的 5 个签名不够，7 天的审查期也足够发现问题。

执法

Through our investigation we were able to confirm Lazarus Group and APT38, cyber actors associated with the DPRK, are responsible for the theft of $620 million in Ethereum reported on March 29.

FBI 声明，2022-04-14[3]

OFAC 早在 2019 年 9 月就制裁了 Lazarus Group。2022 年 4 月 14 日和 22 日，它先后把攻击者的主地址和另外 3 个以太坊地址加进 Lazarus Group 的 SDN 条目[4]；5 月 6 日制裁 Blender.io 时，又公布了 4 个 Lazarus 用来洗这笔钱的钱包地址[9]。归因由 FBI 作出，制裁针对的是组织和地址，本站没有查到针对具体个人的公开起诉。

2024 年的另一次事故

2024 年 8 月 6 日，Ronin 桥又出了一次事故，与 2022 年无关。一次升级定义了 v3 和 v4 两个初始化函数，实际只调用了 v4；负责设置 _totalOperatorWeight 的 v3 没有执行，最低投票权重因此为 0。一个 MEV 机器人抢先提走约 4,000 ETH 和 200 万 USDC，约合 1,200 万美元，事后全数归还，拿到 50 万美元赏金[21][22]。这次没有造成损失，但说明桥的安全依赖于每一次升级都正确执行。

迁到 CCIP 和以太坊 L2

2024 年，Ronin 的验证者投票选择 Chainlink CCIP 作为跨链基础设施，Chainlink 得 10 票，LayerZero 3 票，Axelar 0 票。2025 年 4 月 25 日，旧桥上的全部代币迁到 CCIP，官方估计约合 4.5 亿美元以上[23]。2026 年 5 月 13 日，Ronin 从独立的侧链迁为基于 OP Stack 的以太坊 L2，由 Conduit 主导迁移，RON 仍是 gas 代币[24]。

教训与防御

攻击要成功，必须同时过四关。下表列出每一关当时的状态，以及守住它会怎样：

环节当时的状态守住它会怎样
签名者是否独立9 个验证者中 4 个属于 Sky Mavis攻破一家公司最多拿到 1 个签名，离 5 个很远
临时授权是否收回2021 年 12 月停用后没有撤销攻击者只有 4 个签名，差 1 个过不了门槛
大额提现有没有额外关卡无单笔上限、无每日限额、无延迟超过 5 亿美元的提现会先进入人工审核和审查期
流出有没有监控没有，靠用户提现失败才发现一笔交易转走桥上 99.99% 的 WETH，这样的异常可以在当天发现并暂停

第三关是 Ronin 新桥补上的部分。下面的示意代码表达的是同一类思路：签名够数只是必要条件，大额提现还要更高的签名比例、排队等待和人工确认。

// 示意：按金额分级的提现关卡，不是 Ronin 的实际代码
function requiredWeight(uint256 usdValue) internal pure returns (uint256 pct) {
  if (usdValue >= 10_000_000e18) return 90;   // 第三档：90% 签名 + 人工审核 + 审查期
  if (usdValue >= 1_000_000e18) return 90;    // 第二档：90% 签名
  return 70;                                  // 第一档：70% 签名
}

function withdraw(Receipt calldata r, bytes calldata sigs) external {
  uint256 usd = priceOf(r.token, r.amount);
  require(signedWeight(r, sigs) * 100 >= requiredWeight(usd) * totalWeight, "sigs");
  // 大额：先锁定，审查期满且人工批准后才放款
  if (usd >= 10_000_000e18) {
    locked[hash(r)] = block.timestamp + 7 days;
    return;
  }
  // 每日限额：当天累计流出不能超过上限
  require(dailyOut[today()] + usd <= dailyLimit, "daily limit");
  dailyOut[today()] += usd;
  release(r);
}

示意代码，省略了价格来源、重放保护、审查期内的取消流程等细节。档位与限额数字取自 Ronin 新桥公告[15]。

给跨链桥和多签的设计者
  • 按“背后是谁”数签名者，不按节点数。同一家公司的 4 个节点，遇到一次入侵就等于 1 个。
  • 临时授权要写明到期时间并自动失效。Axie DAO 的白名单本该只存在一个月，实际多活了三个多月。
  • 不要只靠签名。单笔上限、每日限额、大额延迟和人工复核，是签名者失守之后的最后一道防线。
  • 监控桥的余额和大额流出，异常时自动暂停。桥在一笔交易里蒸发 99.99% 的 WETH，本该是最容易触发的告警。
  • 管理员权限和验证者权限一样要分散。一把能改门槛、能增删验证者的 admin 私钥，本身就是又一个单点。
给团队
  • 签名密钥所在的机器要和员工办公环境隔离，员工电脑被攻破后不应该能一路走到验证者节点。Sky Mavis 事后要求员工使用工作专用设备，并提出建立零信任架构[2]。
  • 把“陌生招聘方发来的文件”当成攻击面。在加密行业，几轮看起来正常的面试可能就是攻击的一部分。
  • 出事后先止血再公告。Sky Mavis 在公告前几小时就把门槛提到 8/9，这一步做得对；但被盗的资金在六天前就已经离开了桥。
给评估跨链桥的人
  • 看签名门槛的同时，看签名者分别是谁、彼此是否独立、谁能修改门槛，以及有没有限额和延迟。“9 个验证者”这个数字本身说明不了什么。
