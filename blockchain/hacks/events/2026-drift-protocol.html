区块链被盗事件编年史

总览　/　2026 年　/　十亿美元级失守与信任链

Drift Protocol 被盗 2.85 亿美元

2026 年 4 月 1 日，两笔相隔一秒的预签名交易把 Drift Protocol 的管理员权限交给了攻击者。攻击者随即把自己发行、几乎没有流动性的代币设成抵押品，借空了金库里约 2.85 亿美元的真实资产。程序没有漏洞，签名也是安全委员会成员亲手签的：攻击者冒充一家量化交易公司，在多国行业会议上和 Drift 贡献者当面往来了近半年。

概要

Drift 是 Solana 上最大的去中心化永续合约交易所，协议的管理权限由一个“安全委员会”（Security Council）多签掌握。攻击者没有偷私钥，也没有找代码漏洞，而是让多签成员在看似例行的交易上签了字。这些交易用 Solana 的 durable nonce 机制构造，签名不会过期；里面藏着转移管理员权限的授权。被盗前几天，Drift 刚把安全委员会迁移到 5 人中任 2 人即可执行、没有时间锁的新多签。

4 月 1 日 16:05:18（UTC），攻击者提交第一笔预签名交易，提议把管理员权限转给自己的地址；一秒后第二笔交易完成批准和执行[11]。拿到权限后，攻击者把 3 月 12 日部署、靠自买自卖做出约 1 美元“价格”的 CVT 代币设为抵押品，放开提现限额，存入约 5 亿枚 CVT，借走 JLP、USDC、SOL、cbBTC 等 19 种真实资产[1][8][11]。TRM 统计其中 31 笔提现在约 12 分钟内完成[8]。

赃款被换成 USDC，经 Circle 的跨链协议 CCTP 转到以太坊，再换成约 13 万枚 ETH。Circle 在这几个小时里没有冻结，因此遭到批评并被用户起诉[21][23]。Drift 援引 Mandiant 的取证，把攻击归于朝鲜组织 UNC6862[3]。Tether 承诺最多出资 1.275 亿美元、其他伙伴最多 2,000 万美元，帮助 Drift 重启，结算资产从 USDC 换成 USDT[1][25]；7 月 Drift 改名为 Velocity[34]。10 月 1 日开放的恢复代币 DFX 首日只能兑回约 1% 的损失；同月，攻击者把 4 万多枚 ETH 转进了 Tornado Cash[4][32]。

背景

Solana 上的永续合约交易所

Drift 成立于 2021 年，提供永续合约、现货、借贷和金库（vault）产品，联合创始人 Cindy Leow 曾说想把它做成“加密世界的 Robinhood”[12]。到 2024 年底，Drift 自称有 20 万名交易者、累计交易量超过 550 亿美元[14]。被盗前它的锁仓量约 5.5 亿美元[10][35]。

Drift 的所有借贷市场共用一个流动性池，存款人和借款人的资金在同一个池子里[2]。不少 Solana 协议又把用户资金存进 Drift 的金库做杠杆收益或做市，Drift 因此成了它们的底层依赖。用假抵押品借走的，是所有存款人的钱。

谁握着管理权限

Drift 主程序里有一个全局 State 账户，其中的 admin 字段决定谁能上架新市场、更换预言机、调整风险参数和提现限额。这项权限由安全委员会多签掌握[11][14]。2026 年 3 月下旬，Drift 把安全委员会迁移到一套新配置：5 名签名人中任意 2 人同意即可执行，时间锁为零。迁移日期 TRM 记为 3 月 27 日，Chainalysis 记为 3 月 26 日（两家记录相差一天）[8][11]。公开材料没有说明为什么在这时迁移，也没有给出旧配置的门限和延迟。

朝鲜盗币的又一种打法

据 Elliptic 统计，近年朝鲜相关黑客盗取的加密资产已超过 65 亿美元[10]，单笔最大的是 2025 年 2 月的 Bybit（14.6 亿美元）。以往这些团伙主要在线上接近目标：视频通话、远程工作岗位、假招聘面试[22]。Drift 一案不同，攻击者安排的中间人在多个国家的行业会议上和 Drift 贡献者当面交往了约半年。TRM 认为，这在朝鲜漫长的盗币行动中可能是第一次[9]。

攻击原理

Drift 反复强调，攻击者没有利用程序或合约的漏洞，也没有助记词泄露[14]。攻击用到的每条指令都是程序允许的管理员操作，每个签名都来自真实的签名人。攻击能成功，是因为四层控制同时失效，而每一层都默认上一层已经把过关：签名人没看懂自己签的是什么；durable nonce 让签名一直有效；多签只要两个签名，而且没有等待期；程序只检查签名者是不是 admin，不管 admin 要做什么。

admin 能做什么

Drift 程序里大部分“仅限管理员”的指令，账户约束都写成同一个样子：签名者必须等于 State 账户里记录的 admin（少数指令另外接受一把单独的热钱包密钥，例如创建暂不启用的新市场）。转移管理员的指令只是把这个字段改成新值：

// programs/drift/src/instructions/admin.rs（v2.161.0）
#[derive(Accounts)]
pub struct AdminUpdateState<'info> {
    pub admin: Signer<'info>,
    #[account(
        mut,
        has_one = admin          // 唯一的检查：签名者 == state.admin
    )]
    pub state: Box<Account<'info, State>>,
}

pub fn handle_update_admin(ctx: Context<AdminUpdateState>, admin: Pubkey) -> Result<()> {
    msg!("admin: {:?} -> {:?}", ctx.accounts.state.admin, admin);
    ctx.accounts.state.admin = admin;   // 立即生效：新地址不用确认，没有等待期
    Ok(())
}

来源：velocity-exchange/protocol-v2 仓库（原 drift-labs/protocol-v2）v2.161.0 标签，admin.rs 第 5732–5740 行、第 4425–4429 行[5]。v2.161.0 发布于 2026-03-30，是被盗前最后一个版本；链上实际部署的版本未经本站核对。

这几行本身没有错，权限检查写得很清楚。问题在于程序把所有防护都交给了 admin 背后的那一层：如果 admin 是多签，多签的门限和时间锁就是这些操作前唯一的关口，程序自己不提供任何延迟。按 Chainalysis 的还原，攻击者从提交“把管理员转给新地址”的提案到它被批准执行，只隔了一秒[11]。公开报告没有逐条列出攻击者调用的指令，上面的代码用来说明这项权限有多大，不是对链上交易的还原。

提现限额是怎么被放开的

Drift 的每个现货市场有一个提现保护阈值 withdraw_guard_threshold。它和市场存款余额的时间加权平均值一起，决定一笔提现之后市场里至少要剩多少存款。这个值同样由 admin 用一条指令直接改写：

// programs/drift/src/instructions/admin.rs（v2.161.0）
pub fn handle_update_withdraw_guard_threshold(
    ctx: Context<AdminUpdateSpotMarket>,   // 同样只要求签名者 == state.admin
    withdraw_guard_threshold: u64,
) -> Result<()> {
    let spot_market = &mut load_mut!(ctx.accounts.spot_market)?;
    // ……（两行日志输出从略）……
    spot_market.withdraw_guard_threshold = withdraw_guard_threshold;   // 立即生效
    Ok(())
}

// programs/drift/src/math/spot_withdraw.rs（v2.161.0）
pub fn calculate_min_deposit_token_amount(
    deposit_token_twap: u128,
    withdraw_guard_threshold: u128,
) -> DriftResult<u128> {
    // minimum required deposit amount after withdrawal
    // minimum deposit amount lower of 75% of TWAP or withdrawal guard threshold below TWAP
    // for high withdrawal guard threshold, minimum deposit amount is 0
    let min_deposit_token = deposit_token_twap.safe_sub(
        (deposit_token_twap / 4)
            .max(withdraw_guard_threshold.min(deposit_token_twap)),
    )?;
    // 阈值 ≥ 存款均值时，下限变成 0
    Ok(min_deposit_token)
}

来源：同上，admin.rs 第 2943–2960 行，spot_withdraw.rs 第 14–26 行[5]。英文注释是原有的，中文注释是本站加的；省略了 access_control 属性和日志输出，过长的一行做了换行。

阈值小于存款均值的四分之一时，提现后的存款不能低于均值的 75%，也就是一段时间里最多只能取走约四分之一，相当于一道防挤兑的限速。阈值越大，这条下限越低；阈值大于等于存款均值时，下限变成 0，限速就没有了。借款上限的计算（calculate_max_borrow_token_amount）同样以这个阈值为下限。TRM 说攻击者把提现限额“调到极端水平”，BleepingComputer 转述 Drift 的说法是“移除了预设的提现限额”[8][14]，指的都是这一类参数。具体改了哪些市场、改成多少，公开材料没有列出。

新抵押品的上架门槛

Drift 用 initialize_spot_market 指令创建新的现货市场，预言机来源、抵押权重、资产分级、提现保护阈值都在这一条指令里设定。程序只检查参数是否自洽：预言机能不能读出价格，资产权重是否不超过 100%（也就是最高可以和 USDC 一样按面值计入抵押），代币精度是否不低于 5 位[5]。它不判断这个代币有没有真实流动性、存在了多久、值不值得当抵押品，这些都由 admin 决定。所以拿到 admin，就能把任何能读出价格的代币变成抵押品。

CVT 就是为此准备的。它在 3 月 12 日部署，总量 7.5 亿枚，攻击者控制约 80%。Raydium 池子里的真实流动性，Chainalysis 说只有约 500 美元，TRM 说是“几千美元”（两家说法不同）。攻击者在自己的钱包之间来回交易，做出一段约 1 美元的价格历史[8][11]。上架时，CVT 只存在了 20 天[11]。

CVT 的价格从哪来，说法不一

TRM 说是 Drift 的预言机“读到了”这段人造的价格信号[8]；Chainalysis 说给 Drift 报价的预言机本身就由攻击者控制[11]。两种说法的区别在于预言机账户是不是攻击者部署的。Drift 支持 Pyth、Switchboard On-Demand 等多种预言机来源[5]，公开材料没有说明 CVT 市场配置的是哪一个。

durable nonce：不会过期的签名

Solana 交易里有一个 recent_blockhash 字段，用来防止重放。它引用的区块哈希太旧（Anza 的文档写的是约 2 分钟），网络就拒收这笔交易[7]，所以普通签名很快就会作废。离线签名、托管机构这类需要更长时间的场景，用的是 durable nonce：先建一个 nonce 账户存一个值，交易把这个值填进 recent_blockhash，并把 AdvanceNonceAccount 作为第一条指令。运行时只检查这个值和账户里存的是否一致，不看时间[7]。

// 示意：两种交易的区别在 recent_blockhash 和第一条指令
普通交易
  recent_blockhash = 最近的区块哈希        // 约 2 分钟后过期，签名随之作废
  指令 1..n        = 要做的事

durable nonce 交易
  recent_blockhash = nonce 账户里存的值    // 只要这个值没被推进，就一直有效
  指令 0           = AdvanceNonceAccount   // 必须放在第一条
  指令 1..n        = 要做的事              // 签完之后，何时提交由持有签名的人决定

示意代码，依据 Anza 文档《Durable Transaction Nonces》的规则[7]，不是攻击交易本身。

这改变了“签名”的含义。普通签名两分钟就失效，签名人即使签错了，攻击者也只能当场用掉。durable nonce 签名只要 nonce 没被推进，几天、几周后照样能提交，像一张不写日期的支票。Chainalysis 的还原是：3 月 23 日，攻击者创建了几个 durable nonce 账户，其中一些和真实的安全委员会成员相关；至少两名成员签下了自己没有完全看懂的交易，也就是盲签（blind signing）。迁移产生了新的多签账户，链上记录显示攻击者又拿到了新多签签名人的签名，重新凑齐了管理员操作需要的 2/5[11]。

签名具体是怎么拿到的，各家的说法有不同侧重。CoinDesk 转述 Drift：设备被入侵后，攻击者就有了拿到两份多签批准所需的东西[15]。TRM 的说法是用社会工程诱导签名人预签“看似例行”的交易[8]。签名人看到的界面是否被篡改，还是被骗签了别的东西，公开材料没有讲清楚。

零时间锁

多签加时间锁，本意是在“批准”和“执行”之间留一段公开可见的时间，让其他签名人和监控系统有机会发现并叫停。迁移后的新多签没有这段时间，两个签名凑齐就立刻执行。再加上 durable nonce 让签名可以事先攒好，攻击者得以把提案、批准、执行压进相隔一秒的两笔交易。TRM 认为，3 月 27 日去掉时间锁，正好抹掉了本可用来发现和干预的窗口[8]。Drift 事后的整改措施之一，就是给所有关键管理操作加上时间锁和实时告警[1]。

社会工程部分来自 Drift 自己的调查。Chainalysis 发文时特别注明，这部分当时还没有经过第三方调查独立核实[11]。链上部分来自 TRM 和 Chainalysis 的还原。

  1. 建立信任（2025 年秋至 2026 年 3 月）一伙自称量化交易公司的人在大型加密会议上接触 Drift 贡献者，之后在 Telegram 上讨论交易策略和金库集成，又在多国会议上多次见面。他们按 Drift 的流程填写了多份策略表格，接入一个 Ecosystem Vault，存入超过 100 万美元自有资金[13][15]。Drift 说，到攻击时这段关系已近半年，“这些人不是陌生人”；当面见到的人并非朝鲜人，而是朝鲜方面安排的第三方中间人[13][15]。
  2. 入侵设备Drift 列出几种可能的途径。一名贡献者克隆了对方分享的代码仓库，可能触发了 VSCode 和 Cursor 的一个已知漏洞：只要在编辑器里打开文件或文件夹，就会静默执行任意代码。另一名贡献者被劝说安装了一个 TestFlight 测试版应用，它可能带有恶意代码[13][15][19]。攻击发生后，对方把和 Drift 的 Telegram 聊天记录全部删除[13]。
  3. 准备资金和假代币（3 月 11 日至 12 日）从 Tornado Cash 取出 10 ETH 作为启动资金，部署 CVT 并制造价格历史[8]。
  4. 攒签名（3 月 23 日至 30 日）创建 durable nonce 账户，让安全委员会成员预签暗藏授权的交易；多签迁移后，再拿到新签名人的签名[8][11]。
  5. 接管（4 月 1 日 16:05:18 至 19，UTC）Drift 的描述是攻击者先发了一笔正常交易，紧接着执行预签名的恶意交易[14]。Chainalysis 记录的第一笔交易提议把管理员转给 H7PiGqqUaanBovwKgEtreJbKmQe6dbq6VTrw6guy7ZgL，一秒后第二笔交易批准并执行[11]。
  6. 改参数，存假抵押品把 CVT 设为可用的抵押品，把借款上限设得极高，放宽风险参数，再存入 5 亿枚 CVT。按人造的 1 美元价格，系统认为这笔抵押品值约 5 亿美元[11]。
  7. 提走真实资产被提空的包括 JLP Delta Neutral、SOL Super Staking、BTC Super Staking 等金库，单笔最大的是约 4,170 万枚 JLP，约 1.55 亿美元[10]。TRM 统计 31 笔提现在约 12 分钟内完成[8]；Chainalysis 说最大的几笔集中在最初几分钟，此后断断续续持续约 2.5 小时，最后一笔在 18:31[11]。
  8. 边偷边洗提取还没结束，攻击者已经开始用 Jupiter 把代币换成 USDC 并跨链，第一笔资金在接管约 23 分钟后到达以太坊[9][11]。

关于“多快”，各家说法差得很远：CoinDesk 写“不到一分钟”[15]，TRM 写“约 12 分钟”[8]，Chainalysis 写“约 2.5 小时”[11]。三者说的是不同阶段：接管本身用了 1 秒，大额提现集中在几分钟内，协议直到 18:31 才完全停下。

金额为什么有好几个

TRM 和 Chainalysis 给出的总额是约 2.85 亿美元，PeckShield 当天的统计也是 2.85 亿美元；Elliptic 算出 2.86 亿美元[8][10][11][14]。Drift 最初的估计是约 2.8 亿美元[14]，CoinDesk 4 月 5 日的标题用的是 2.7 亿美元[15]。Drift 自己后来的数字又有三个：4 月 16 日资产表合计约 2.957 亿美元；5 月 5 日方案的恢复目标是 295,426,725.97 美元；10 月发行的 DFX 总量是 299,500,810.998 枚，每枚对应 1 USDT 的核定损失[1][2][4]。第三方和 Drift 的差别主要来自估值时点和统计范围[31]；DFX 总量比 5 月的目标多出约 400 万，Drift 没有解释原因（本站未找到说明）。本页标题沿用多数第三方使用的 2.85 亿美元。

从 Solana 到以太坊

攻击者主要通过 Jupiter 把各种代币换成 USDC，再用 Circle 的跨链协议 CCTP 转到以太坊，换成 ETH[9][10]。诉状称约 2.3 亿美元 USDC 经 CCTP 跨链，用了约 8 小时[23]；Cointelegraph 援引 Elliptic 称，攻击者在美国工作时间里通过 Circle 的跨链技术做了 100 多笔交易[24]。到 5 月初，约 130,259 枚 ETH（约 2.93 亿美元）集中在 4 个以太坊钱包里[2]。

被拦下的只有很少一部分。经 CCTP 的 3 笔转账被冻结，合计约 336 万 USDC，Drift 正在申请扣押令，以便销毁后重新发给协议。经 Wormhole 的 2 笔转账（约 59.37 枚 WBTC、约 557.90 枚 WETH）被 Wormhole 的限流机制 Governor 延迟到 7 月下旬[2]。

洗钱的节奏

TRM 判断，这个团伙和 TraderTraitor（Lazarus）不是同一支。它的习惯是先把赃款放上几个月甚至几年，再分阶段兑现[9]。以太坊上的 ETH 从 4 月到 7 月下旬确实没有动过。

Coin Edition 转述 Drift Foundation 的说法：被冻结的约 920 万美元，是攻击者 8 月经 Tornado Cash 转出的资金，由哪个机构冻结没有说明。Drift Foundation 只说这笔钱要走执法程序才能释放，需要时间[30]。它和 5 月提到的 336 万 USDC、Wormhole 延迟的两笔转账是什么关系，本站没有找到说明。

影响

Drift 自身

Drift 的锁仓量从约 5.5 亿美元跌到 2.5 亿美元以下，DRIFT 代币跌了 40% 以上[8][10]。借贷存款、金库存款和交易保证金都受影响，协议的全部功能被冻结；保险基金的资产没有受损[14]。按 Elliptic 和 TRM 的统计，这是 2026 年到当时为止最大的 DeFi 被盗案，在 Solana 历史上仅次于 2022 年 3.26 亿美元的 Wormhole[8][10]。

沿着依赖关系扩散

Chainalysis 统计，至少 20 个依赖 Drift 流动性、金库或策略的协议报告了中断、暂停或损失[11]。收益协议 Carrot 通过 Drift 的金库和流动性仓位持有大量敞口，事发后暂停了铸造和赎回，约一半锁仓处于风险中，损失估计超过 800 万美元。4 月 30 日 Carrot 宣布关停，给用户留到 5 月 14 日自行提款[27]。6 月 15 日，支付平台 Pyra 也因 Drift 相关损失宣布关停，注销了已发出的支付卡[28]。Solana 整体的 DeFi 锁仓量在事发后出现两位数百分比的下跌，到 9 月底才回到 65 亿美元以上，其中有 SOL 价格上涨的因素[35]。

朝鲜的 2026 年

17 天后，KelpDAO 又被盗约 2.92 亿美元，同样被归于朝鲜。TRM 统计，这两起合计约 5.77 亿美元，占 2026 年前 4 个月加密货币黑客攻击损失的 76%[9]。到 6 月底，朝鲜相关的盗窃约 6.43 亿美元，占上半年的 66%；针对基础设施和操作流程的入侵只占事件数的约 15%，却造成了约 76% 的损失[18]。

冻结还是不冻结

Circle 成了争议的中心。攻击者花了几个小时把赃款换成 USDC 再跨链，ZachXBT 等人认为 Circle 至少有 6 小时可以冻结却没有动作[21]，诉状的说法是约 8 小时[23]。批评者拿 Circle 以前冻结过的钱包作对比；原告律师指出，Drift 事件前约一周，Circle 刚因一起密封审理的民事案件冻结了 16 个 USDC 钱包[24]。

Circle 的立场分两层。CEO Jeremy Allaire 说，冻结应当在收到法院命令后进行，不能由公司自行决定：“一个会因为推特上的压力而冻结的稳定币，就是谁嗓门大谁就能触发冻结的稳定币。”[23]首席战略官 Dante Disparte 在公司博客里写道，冻结是合规义务，“只在有权机关通过合法程序要求时”才执行；他同时承认，更快干预的技术工具已经存在，缺的是授权这种干预的法律框架，Circle 正在推动“安全港”规则[20]。ARK Invest 的 Lorenzo Valente 支持 Circle 的做法，理由是没有法律命令就冻结，“以后每一次冻结都是主观判断，每一次不冻结都是政治表态”[24]。

Tether 随后以救助者的身份出现，条件之一是 Drift 改用 USDT[23][25]。

同一类攻击

Drift 不是第一个“签名人被骗签”的案子。下表列出本站收录的几起，共同点是私钥没有直接被盗，签名人签下的东西和他们以为的不一样。

后续处置

暂停与快照

Drift 在攻击当天暂停存取款。协议在 18:31:47（UTC）完全暂停，这一刻被定为用户仓位的快照时间，以便把攻击窗口内非攻击者地址借款提走的部分也算进去。名义价值按 16:06:00 的预言机价格计算，因为之后的市场价格已被攻击扭曲[2]。剩余资产没有直接退给存款人：所有借贷市场共用一个资金池，在借款还清之前先把存款退给存款人，会抽走其他账户依赖的流动性[2]。

喊话与赏金

4 月 3 日，Drift 从以太坊地址 0x0934faC45f2883dd5906d09aCfFdb5D18aAdC105 向持有赃款的 4 个钱包发出链上消息，称已查明“与攻击有关的各方的关键信息”，并表示“我们准备好谈了”[16]。Curve 创始人 Michael Egorov 对 Decrypt 说，如果是朝鲜所为，追回的概率是零[16]。5 月，Drift 和 Bybit 等伙伴推出公开赏金：成功追回的资产，给 10%[2]。

归因经过了几次修正

4 月 2 日，Elliptic 和 TRM 根据链上行为、洗钱手法和网络层面的迹象指向朝鲜[8][10]，列出的迹象包括使用 Tornado Cash、部署时间落在平壤时间上午、跨链速度和规模与 Bybit 案相似[14]。4 月 5 日，Drift 依据 SEAL 911 等的调查，以“中高置信度”认定攻击者与 2024 年 10 月 Radiant Capital 被盗约 5,000 万美元的是同一伙人，即 Mandiant 追踪的 UNC4736（又称 AppleJeus、Citrine Sleet），依据是资金流向和人设的重合；当时 Mandiant 尚未确认[10][13][19]。TRM 4 月底的判断是：这是一个不同于 TraderTraitor 的朝鲜团伙，具体分支仍在调查[9]。6 月 3 日，Drift 公布 Mandiant 的取证结论：攻击者是朝鲜组织 UNC6862，与在其他平台发动类似攻击的国家支持团伙“有直接关联”[3]。

这些都是受害方和安全公司的判断。截至 2026 年 10 月，本站没有找到美国政府机构就此案公开发布的归因。曾在 Mandiant 调查团队工作多年、现任 DTEX 国家级威胁情报负责人的 Michael Barnhart 对 Recorded Future News 说，据接近调查的人士判断，当面接触 Drift 的三人中，两人可能并不知情，另一人很可能是故意的，因为他事后清空了自己的 Telegram 账号[13]。这是他个人的说法，Drift 没有公开证实。

Tether 牵头的救助

4 月 16 日，Drift 宣布与 Tether 等伙伴合作：Tether 拟出资最多 1.275 亿美元，其他伙伴拟出资 2,000 万美元，形式包括一笔 1 亿美元的收入挂钩信贷额度、生态拨款和给做市商的贷款[1]。Tether 说资金将“按平台表现分阶段投入”[25]；5 月的方案进一步写明，Tether 的配套资金按交易所上一季度的收入投放[2]。作为重启的一部分，Drift 把结算资产从 USDC 换成 USDT，涉及超过 12.8 万名用户和 35 个以上的生态团队[25]；Tether 另外提供一笔 2,000 万美元的做市资金[2]。

恢复代币 DFX

5 月 5 日的方案定下了基本框架：每个受影响的钱包按核定损失 1:1 领取恢复代币，与 DRIFT 治理代币分开；恢复池先用协议剩余资产启动（当时约 380 万美元），再靠交易所收入、Tether 配套资金和伙伴资金逐步补充，直到覆盖全部损失，届时未赎回的代币可以按面值兑付[2]。

10 月 1 日，DFX 开放领取和赎回，领取截止 2028 年 1 月 1 日，逾期未领的销毁。赎回价等于恢复池余额除以流通量，赎回即销毁。每天 0 点（UTC），重启后交易所的净协议收入按阶梯比例注入恢复池：3 万 USDT 以内 60%，3 万到 10 万 70%，超过 10 万 90%[4]。开放当天池子里约 311 万 USDT，每枚 DFX 约兑 0.0104 USDT，即损失的约 1%[4][29]。The Cryptonomist 报道，首日收入只给池子带来约 31 USDT，Tether 和伙伴承诺的资金还没有出现在仪表盘上；当时已有 216,480 枚 DFX 被赎回，换得约 2,250 USDT[29]。CryptoSlate 提醒，承诺的是资金上限，不是已经存入池子的现金[36]。

和 5 月的方案相比，10 月的规则有几处变化：5 月写的是恢复池超过 500 万美元才开放赎回，10 月开放时池子约 311 万；收入注入从每季度改为每天；恢复目标从 295,426,725.97 美元变成约 2.995 亿枚 DFX[2][4]。保险基金没有拿来赔这次的损失，Drift 的解释是它只覆盖交易穿仓，不覆盖攻击损失；保险基金的存款从 7 月 7 日起可以提取[28]。

改名 Velocity 重启

4 月起，Drift 把重建的重点放在安全上：OtterSec 负责代码重构和全面审计，Asymmetric 负责运营安全；新程序部署在全新地址，所有密钥轮换，升级到 Anchor 1.0 并删去不用的代码；Isolated Markets、Amplify 等收益产品下线，交易所收缩到永续合约[1][2]。安全委员会换成由 Solana 基础设施、DeFi、安全、流动性等领域人士和生态贡献者组成的新多签；签名人必须用专用签名设备，在签名界面之外独立核对交易内容；所有关键管理操作加时间锁和实时告警；所有签名人禁用 durable nonce[1]。6 月，前 Helium 协议工程负责人 Noah Prince 加入主持重建，Gauntlet 的前成员参与风险参数设计[3]。

7 月 2 日，Drift 宣布更名为 Velocity[34]。本站 10 月访问时，原来的 docs.drift.trade 已跳转到 Velocity 的文档，GitHub 上的 protocol-v2 仓库也已迁到 velocity-exchange 名下并归档[5][6]。Velocity 的文档按后果把管理权限分成三层：冷钥匙是根权限，留给可能削弱其他安全措施的改动，例如更换预言机；温钥匙负责日常参数调整，带时间锁；热钥匙一个角色一种权限，只能做一件事。另有一把单独的暂停钥匙，没有时间锁，但只能加暂停、不能解除，被盗了最多造成拒绝服务，不会变成盗窃[6]。文档同时写明，冷钥匙层的改动没有时间锁；程序代码要等分叉后的审计报告定稿后才开源[6]。到 10 月 1 日，Velocity 已在运行，并开始按天把收入存进恢复池[4]。

诉讼

起诉 Circle 的是密苏里州居民 Joshua McCollum，他在 Drift 上有约 2.35 万美元的资产。他代表 Drift 投资者在马萨诸塞州联邦法院提起集体诉讼，指控 Circle 协助侵占和过失：Circle 有能力冻结，却“在数小时内明知地放任攻击者使用其技术和服务”；CCTP 唯一的用途是资金转移，按《银行保密法》本应监控可疑活动[23]。提交日期，Decrypt 写的是 4 月 14 日[26]，Cointelegraph 写的是“周三”，即 4 月 15 日[24]。Circle 的回应是，公司受监管，遵守制裁、执法命令和法院要求[26]。截至 2026 年 10 月，本站没有查到这起诉讼的实质性裁决。

教训与防御

给协议开发者
  • 按后果给权限分级。日常运行用的钥匙不该能转移管理员或更换预言机。Velocity 重建后的冷、温、热三层加单独暂停钥匙，是一种可参考的做法。
  • 危险操作在程序层面就要有延迟或两步确认。转移管理员应当是“提议”加“新地址接受”两步，中间留出等待期，不要一条指令直接改写。
  • 时间锁本身也要受保护。Drift 被盗前几天刚迁移到零时间锁的多签。降低门限、缩短延迟的操作，应当和它保护的操作一样难做、一样公开。
  • 新抵押品上架要有程序强制的门槛：最低流动性、最短上线时长、时间加权价格、初始抵押权重为 0、存款上限。CVT 上架时只存在了 20 天，池子里的真实流动性只有几百到几千美元。
  • 提现熔断不能只由 admin 一把钥匙控制。Drift 的金库被连续提取两个多小时，没有任何自动机制叫停[11]。
给多签签名人
  • 在独立的设备上核对交易的实际内容，不要只信签名界面上的文字。Drift 重启后要求签名人用专用设备，并在签名界面之外单独核对。
  • 遇到 durable nonce 交易（第一条指令是 AdvanceNonceAccount）要格外警惕。这种签名不会过期，可能在任何时候被提交，没有必要就不签。
  • 签名设备不做开发，也不试用新软件。按 Drift 的调查，打开一个陌生的代码仓库、装一个测试版应用，就可能让设备被控制。
  • 见过面、合作过几个月，不等于可信。Drift 被盗前，双方已经往来近半年，对方还存入了 100 万美元。
给整个行业
  • 赃款停留在可冻结资产里的时间，就是行业的响应窗口。这一次窗口只有几个小时，大部分资金随后变成了没人能冻结的 ETH。要让冻结更快，需要事先约定好的法律程序和授权渠道，事后的舆论压力替代不了它们。
  • 多签被骗签的事件一再发生，说明增加签名人数解决不了“签名人不知道自己在签什么”的问题。签名前对交易做独立的模拟和意图校验，比多加一个签名人更有用。
  • DeFi 协议互相嵌套会放大损失。把资金存进别的协议时，要把对方的管理权限和时间锁当作自己的风险来评估。
