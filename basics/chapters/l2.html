L2：Base 与 OP Mainnet

Base 和 OP Mainnet 是怎么借用以太坊安全的，钱锁在哪、数据交到哪、争议去哪裁决，以及 Base 为什么没有自己的币。

机制

Base 到底是什么

常听到一句话：“L2 本质上是以太坊上的一个智能合约。”这句话抓住了关键，但只说对了一半。

对的那一半

  • Base 的钱锁在以太坊的合约里。你在 Base 上的每一个 ETH，都对应以太坊合约里锁着的一个 ETH
  • Base 的交易数据要发到以太坊上存档
  • Base 的状态（账本快照）要提交到以太坊合约，谁不服可以在以太坊上挑战
  • 以太坊合约说了算：提现能否放款，由以太坊上的合约判定

不准确的那一半

  • Base 的交易不在以太坊上执行。它有自己的节点、自己的区块（每 2 秒一个）、自己的 RPC 和区块浏览器
  • 一笔 Base 交易不会触发以太坊合约运行，以太坊只是事后收到一大批压缩数据
  • 所以更准确的说法是：Base = 链下执行的 EVM 链 + 以太坊上的一组合约

打个比方：以太坊是总部，管着金库、档案室和仲裁庭；Base 是营业厅，日常业务都在营业厅办完，速度快、手续费低。但营业厅必须定期把全部流水交到档案室，钱永远锁在总部金库，有争议去总部仲裁。

2026 年的重要变化：Base 不再是标准的 OP Stack 链。Base 2026-02-18 宣布“未来几个月逐步离开 OP Stack”，但保持与 OP Stack 规范兼容；2026-03 退出 Optimism 的 Superchain 治理，并取消了链上收入分成；之后用自己命名的升级（Azul、Beryl、Cobalt）换掉了证明系统。所以下面先讲 OP Stack 的标准机制（OP Mainnet 现在仍是这样），再用一张表讲 Base 改了哪些地方。

四个角色

Sequencer

排序器

接收用户交易、排序、执行、每 2 秒出一个 L2 区块。Base 官方文档写明目前只有一个活跃排序器（一个高可用集群，由 Base 运行），另外每约 200 毫秒发一个 Flashblock 作为预确认。

Batcher

打包上传者

把成千上万笔 L2 交易压缩，打包成 blob 发到以太坊的 BatchInbox。这一步付的是以太坊的数据费（blob 见第 05 章）。

Proposer

状态提交者

定期把“执行完这些交易后，L2 的账本长这样”的状态根提交到以太坊的 DisputeGameFactory。

Challenger

挑战者（任何人）

从以太坊下载交易数据自己重算。发现状态根不对，就在挑战期内发起欺诈证明。OP Mainnet 2024-06 开放无许可挑战，Base 2024-10-30 跟进；Base 2026-05 起改用 TEE + ZK 多重证明。

一笔交易在 L2 上的一生

三种“确认”，钱包和桥看的不是同一个

状态大约多久意味着什么谁会用它
unsafe~2 秒（Base 的 Flashblock 约 0.2 秒）排序器说“收到并执行了”。只是排序器的承诺钱包、普通 DApp
safeBase 约 2 分钟交易数据已经发到以太坊，排序器没法偷偷改历史中等金额的业务
finalizedBase 约 20 分钟包含这批数据的以太坊区块已经最终确定交易所、CCTP、跨链桥
提现到 L1OP Mainnet 7 天；Base 1–5 天状态根熬过挑战期，以太坊合约才放款官方桥提现

“finalized”只说明 Base 的交易历史不会再变，但官方桥提现还要单独再等证明期，因为以太坊合约要确认的是“L2 的账本算对了”，不只是“数据已经存档”。CCTP 不走这个等待期，它在 Base 上 burn、在以太坊上由 Circle 证明后 mint。

Base 有没有自己的币

链付 gas 用有没有自己的代币为什么
BaseETH没有目前没有网络代币。收入来自排序器手续费：用户付的 gas − 付给以太坊的数据费。按 Superchain 规则，原本要把收入的 2.5% 或利润的 15%（取高者）分给 Optimism；2026-03 起这项链上分成已取消
OP MainnetETH有 OP，但只用于治理投票OP 代币不能付 gas，和链的运行无关
BSCBNB有，BNB 就是原生币BSC 是独立 L1，不需要从以太坊搬 ETH，自然用自己的币

关键点：L2 上用 ETH 付 gas，不是因为“没发币所以借用 ETH”。Base 上的 ETH 本来就是以太坊金库合约里锁着的 ETH 的“提货凭证”。就算某个 L2 发了代币（比如 OP），gas 仍然是 ETH。是否发币、发不发，都不改变它的安全来源。

2025-09-15 Base 官方博客写道 “Base is beginning to explore a network token”，并说明还没有关于时间、设计和治理的任何细节。截至 2026-10-27，Base 博客和主流媒体都没有正式发币公告。注意：B20 是 Base 的代币标准名称，不是 Base 的网络代币。

常见误解

“ETH” 到底是链还是币？

两者都叫。Ethereum 是网络，ETH 是它的原生币。Base 和 OP Mainnet 上付 gas 也用 ETH，那是从以太坊通过官方桥搬过来的 ETH，不是新的币。OP 代币是 Optimism 的治理代币，不用来付 gas；Base 没有自己的代币。

L2 为什么提现要等好几天，充值却只要几分钟？

Optimistic Rollup 默认 L2 提交的状态是对的，留出一段时间让任何人提交欺诈证明：OP Mainnet 是 7 天。Base 改用 TEE + ZK 证明后缩短到 5 天，双证明时 1 天。L1 → L2 方向不需要质疑 L1，所以快。CCTP 或第三方流动性桥能让用户绕开等待，代价是信任 Circle 或做市方。
