CryptoKitties 走红：一款养猫游戏堵塞以太坊

2017 年 11 月 28 日，Axiom Zen 在以太坊主网公开上线 CryptoKitties：玩家用 ETH 买卖和繁殖卡通猫，每只猫是合约里的一条记录。12 月 2 日 1 号猫 Genesis 以约 246 ETH 成交，玩家随后大量涌入。到 12 月 4 日，它占以太坊全部交易笔数的 11.77%，待确认的交易约为上线时的六倍，团队两天里两次调高繁殖费。12 月 15 日的核心开发者会议把这次拥堵列为议题，记录写道，gas 上限调到 800 万以后区块仍然基本是满的。游戏的热度 12 月 10 日见顶，此后很快回落；它的合约是 ERC-721 的早期实现，后来被定稿列为先例。

概要

CryptoKitties 由温哥华的 Axiom Zen 开发，感恩节（2017 年 11 月 23 日）先向约 200 人开放，11 月 28 日公开上线[20][22]。每只猫是 KittyCore 合约里的一条记录，核心是出生时就定下、此后不变的 256 位基因。配种要两笔交易：第一笔让母猫怀孕，同时预付一笔繁殖费；冷却结束后，任何人都可以发第二笔交易让小猫出生，领走这笔费用。第一代猫由合约定时拍卖，起价随最近几只的成交价上涨[1][17]。

12 月 2 日，1 号猫 Genesis 以约 246 ETH 成交，消息传开，玩家大量涌入[17][21]。Quartz 引用 ETH Gas Station 的数据，12 月 4 日 CryptoKitties 占以太坊全部交易笔数的 11.77%，两天前约为 4%；按 Etherscan 的数据，待确认的交易约为游戏上线时的六倍[15]。为了让接生交易按时上链，团队 12 月 3 日把繁殖费从 0.001 ETH 调到 0.002 ETH，4 日又调到 0.015 ETH[15][20]。

12 月 15 日第 30 次核心开发者会议的记录写道，矿工把 gas 上限从 670 万调到 800 万，区块仍然基本是满的[7]。开发者讨论了提高读取账户和存储的 gas 价格、无状态客户端等办法[7][9]；一个月后的会议说，长期要靠分片[8]。东南大学的 Xin-Jian Jiang 和香港城市大学的 Xiao Fan Liu 按每天参与游戏的地址数统计，热度上升只持续了不到十天，12 月 10 日见顶，2018 年初已不到高峰的一成[21]。2018 年 3 月，CryptoKitties 融资 1,200 万美元，从 Axiom Zen 分拆出来[23]；开发方 Dapper Labs 后来做了自己的链 Flow[27]。

背景

2017 年底的以太坊

当时以太坊还用工作量证明，KittyCore 的代码按约 15 秒一个区块估算[1]。交易费靠用户自己出价，矿工挑出价高的打包，这套一价拍卖 2021 年才改掉，经过见EIP-1559 与 London 升级。Bloomberg 写道，以太坊的 ether 是仅次于比特币的第二大加密货币，以太坊也被大量用来发行 ICO 代币[16]。以太坊基金会 2018 年 1 月写道，每个节点都要处理每一笔交易，整个系统的处理能力因此受限于单个节点；以太坊每天的交易已经达到 100 万笔，经常跑满容量[12]。

KittyCore 的作者在注释里算过一笔账：猫的编号用 32 位整数，上限“只有”约 40 亿只，看起来不多，可是以太坊当时一年大约只能处理 5 亿笔交易，所以几年之内不会成为问题[1]。一年 5 亿笔，折合每秒约 16 笔（本站换算）。

扩容的办法当时还在纸面上。2017 年 8 月，Joseph Poon 和 Vitalik Buterin 发出 Plasma 的工作草稿，设想让区块链承载每秒大量的状态更新，“可能达到数十亿次”[13]；分片也还在研究阶段[7][12]。同一年，比特币社区为区块大小争执不下，8 月分出 Bitcoin Cash，经过见比特币区块大小之争。

Axiom Zen 和 ERC-721 草案

Axiom Zen 在旧金山和温哥华都有办公室，帮创业项目孵化数字产品。它的传播经理 Bryce Bladon 对 Bloomberg 说，团队想让普通用户也能用上区块链技术，相信这是这项技术被广泛采用的关键一步[16]。

2017 年 9 月 22 日，GitHub 用户 dete 在以太坊 EIPs 仓库开了第 721 号 issue，提出不可替代代币（NFT）的标准接口，动机是让 NFT 能在标准化的钱包里被追踪、在交易所里交易[4]。定稿的 ERC-721 作者栏写的是 Dieter Shirley <dete@axiomzen.co>[5]；VentureBeat 后来称 Shirley 为 Dapper Labs 的 CTO、ERC-721 这项 NFT 标准的原作者[26]。

上线前的漏洞赏金

上线之前，团队在 Rinkeby 测试网办了一次漏洞赏金，时间是 2017 年 11 月 16 日 00:01 至 20 日 23:59（GMT）。范围只有合约代码；按 OWASP 的风险评级给分，1 分折合 1 美元，用 ETH 支付[2]。

赏金开始当天，GitHub 用户 Arachnid 提交了第 4 号 issue，标题是“列出一个用户的全部猫是 O(n²)”。tokensOfOwnerByIndex 每次都从头扫描所有的猫，找某人名下的第几只；猫一共 n 只、其中 m 只属于这个人，列完就要 O(m×n) 的时间，猫一多，即使在链下调用也会慢得没法用[3]。主网合约里没有这个函数，换成了扫描一遍、返回整个列表的 tokensOfOwner，注释写明它绝不能被智能合约代码调用，因为它要遍历整个猫数组[1]。ERC-721 定稿引用了这个 issue，提醒实现者不要在代码里用 for 或 while 循环，否则 gas 成本会随规模无限上涨[5]。

技术机制

CryptoKitties 没有改以太坊的任何规则。它是部署在以太坊上的一组智能合约，买猫、配种、接生、拍卖，每个动作都是一笔普通交易，和网络上的其他交易一起排队，等矿工打包。下面的代码引自 KittyCore 合约（0x06012c8cf97bead5deae237070f9587f8e7a266d）在 Etherscan 上的已验证源码，编译器 v0.4.18[1]。主合约分几层继承：KittyBase 存数据，KittyOwnership 管归属，KittyBreeding 管配种，KittyAuction 和 KittyMinting 管拍卖和发行第一代猫，最后合成 KittyCore；拍卖本身由另外的 ClockAuction 合约处理[1]。

一只猫存了什么

// KittyBase（节选）
struct Kitty {
    uint256 genes;            // 基因，出生时定下，此后不变
    uint64 birthTime;         // 出生时的区块时间戳
    uint64 cooldownEndBlock;  // 冷却到第几个区块结束
    uint32 matronId;          // 母亲的编号，第一代为 0
    uint32 sireId;            // 父亲的编号
    uint32 siringWithId;      // 怀孕时记下父亲的编号，非 0 即怀孕
    uint16 cooldownIndex;     // 冷却档位，每配一次升一档
    uint16 generation;        // 代数：父母中较大的代数加 1
}
uint32[14] public cooldowns = [
    uint32(1 minutes), uint32(2 minutes), uint32(5 minutes), uint32(10 minutes),
    uint32(30 minutes), uint32(1 hours), uint32(2 hours), uint32(4 hours),
    uint32(8 hours), uint32(16 hours), uint32(1 days), uint32(2 days),
    uint32(4 days), uint32(7 days)
];
// An approximation of currently how many seconds are in between blocks.
uint256 public secondsPerBlock = 15;

出处：KittyCore 已验证源码，KittyBase，节选；结构体字段的英文注释从略，数组按每行四项合并[1]。英文注释为原文，中文注释为本站所加。

结构体的注释写道，字段的顺序照以太坊的打包规则排过，一只猫正好占两个 256 位的存储字[1]。写存储按字付 gas，字越少越省。基因的格式没有公开，注释称它“超级机密”；混合基因的算法放在另一个合约 GeneScience 里，主合约只存它的地址[1]。赏金页面说，这些合约能组合出超过 40 亿种外观和基因型[2]。

冷却分 14 档，从 1 分钟到 7 天，每配一次种升一档，升到第 14 档为止；第一代猫从第 1 档（1 分钟）起步，其他猫从第“代数 ÷ 2 取整 + 1”档起步，代数越高，起步的冷却越长[1]。合约读不到钟表，配种时把这一档的秒数除以 secondsPerBlock，折成区块数，加上当前区块号，记进 cooldownEndBlock。按 15 秒一个区块，1 分钟是 4 个区块，7 天是 40,320 个区块（本站换算）。字段名和代码都按区块号算，原注释写的却是“时间戳”[1]。

配一次种，两笔交易

第一笔交易由母猫的主人发出：调用 breedWithAuto，同时付上繁殖费 autoBirthFee。合约检查付款、归属、配种许可、冷却和亲缘关系，然后让母猫怀孕，双方进入冷却。小猫这时还没有出生。冷却结束以后，要有人再发第二笔交易，调用 giveBirth[1]。

// KittyBreeding（节选）
/// @notice The minimum payment required to use breedWithAuto(). This fee goes towards
///  the gas cost paid by whatever calls giveBirth(), and can be dynamically updated by
///  the COO role as the gas price changes.
uint256 public autoBirthFee = 2 finney;      // 0.002 ETH

function setAutoBirthFee(uint256 val) external onlyCOO {
    autoBirthFee = val;                      // 只有 COO 账户能改
}

function breedWithAuto(uint256 _matronId, uint256 _sireId) external payable whenNotPaused {
    require(msg.value >= autoBirthFee);       // 先付繁殖费
    require(_owns(msg.sender, _matronId));    // 母猫必须归调用者
    // ……检查配种许可、双方都不在冷却中、不是近亲……
    _breedWith(_matronId, _sireId);           // 母猫怀孕，双方进入冷却
}

function _triggerCooldown(Kitty storage _kitten) internal {
    // 把这一档冷却的秒数折成区块数，加上当前区块号
    _kitten.cooldownEndBlock =
        uint64((cooldowns[_kitten.cooldownIndex]/secondsPerBlock) + block.number);
    if (_kitten.cooldownIndex < 13) { _kitten.cooldownIndex += 1; }
}

function giveBirth(uint256 _matronId) external whenNotPaused returns(uint256) {
    // ……母猫必须在怀孕中，且 cooldownEndBlock <= 当前区块号……
    uint256 childGenes = geneScience.mixGenes(matron.genes, sire.genes,
                                              matron.cooldownEndBlock - 1);
    address owner = kittyIndexToOwner[_matronId];   // 小猫归母猫的主人
    uint256 kittenId = _createKitty(_matronId, matron.siringWithId, parentGen + 1,
                                    childGenes, owner);
    // ……
    // Send the balance fee to the person who made birth happen.
    msg.sender.send(autoBirthFee);            // 繁殖费付给发这笔交易的人
    return kittenId;
}

出处：KittyCore 已验证源码，KittyBreeding，节选；函数头合成一行，长语句折行，检查的部分从略[1]。英文注释为原文，中文注释为本站所加。

giveBirth 的注释写明，谁都可以调用它，只要愿意付 gas，小猫总是归母猫的主人[1]。这样玩家只要发一笔交易，等着小猫出生就行，第二笔交易由别人代发。setAutoBirthFee 的注释说，这笔钱用来抵消“自动接生程序”（autobirth daemon）付出的 gas[1]；Jiang 和 Liu 把调用 giveBirth 的人称为“接生者”，繁殖费就是付给接生者的 gas 补偿[21]。繁殖费存在合约的状态里，COO 账户随时可以改，不用升级合约[1]。

第一代猫的拍卖

第一代（Gen 0）猫只能由 COO 账户铸造，上限 45,000 只，另有最多 5,000 只推广用的猫。每只 Gen 0 挂出一天的拍卖，价格一天之内从起价降到 0；起价是最近 5 只 Gen 0 成交均价的 1.5 倍，最低 0.01 ETH[1]。TechCrunch 写道，游戏开局有 100 只 Founder 猫，此后每 15 分钟放出一只 Gen 0[17]。买得越快、出价越高，下一只的起价就越高；Mashable 12 月 4 日写道，一只 Gen 0 当时约 7.7 ETH[18]。玩家之间也可以拍卖猫，或者把猫的配种权挂出去出租；在官方市场成交，游戏方抽成交价的 3.75%[21]。

早期的 ERC-721

// KittyOwnership（节选）
string public constant name = "CryptoKitties";
string public constant symbol = "CK";

bytes4 constant InterfaceSignature_ERC721 =
    bytes4(keccak256('name()')) ^
    bytes4(keccak256('symbol()')) ^
    bytes4(keccak256('totalSupply()')) ^
    bytes4(keccak256('balanceOf(address)')) ^
    bytes4(keccak256('ownerOf(uint256)')) ^
    bytes4(keccak256('approve(address,uint256)')) ^
    bytes4(keccak256('transfer(address,uint256)')) ^
    bytes4(keccak256('transferFrom(address,address,uint256)')) ^
    bytes4(keccak256('tokensOfOwner(address)')) ^
    bytes4(keccak256('tokenMetadata(uint256,string)'));

function supportsInterface(bytes4 _interfaceID) external view returns (bool) {
    // 原文这里有一行调试用的注释，写明这个值等于 0x9a20483d
    return ((_interfaceID == InterfaceSignature_ERC165) ||
            (_interfaceID == InterfaceSignature_ERC721));
}

// ClockAuction（节选）：部署时检查猫合约声明支持同一个接口号
bytes4 constant InterfaceSignature_ERC721 = bytes4(0x9a20483d);
require(candidateContract.supportsInterface(InterfaceSignature_ERC721));

出处：KittyCore 已验证源码，KittyOwnership 和 ClockAuction，节选；return 语句折行，ClockAuction 的 require 写在构造函数里[1]。中文注释为本站所加。

KittyOwnership 的标题写明它“符合 ERC-721（草案）”，并链到第 721 号 issue[1]。它把十个函数签名的 Keccak 哈希各取前 4 个字节，异或起来作为接口号，拍卖合约 ClockAuction 部署时反过来检查猫合约是否声明支持这个接口号[1]。这一版接口有 transfer、approve、transferFrom 和返回全部代币的 tokensOfOwner，没有后来定稿里的 safeTransferFrom 和 setApprovalForAll[1][5]。

2018 年 6 月定稿的 ERC-721 规定的 ERC-165 接口号是 0x80ac58cd[5]，和 KittyCore 认的 0x9a20483d 不同。定稿列举 2018 年 2 月时的实现，第一个就是 CryptoKitties，注明它“和本标准的早期版本兼容”；讲到实现可以在哪些情况下拒绝转账时，定稿两次把“CryptoKitties 已部署的合约”列为先例：合约暂停时禁止转账，禁止某些地址接收 NFT[5]。

为什么会堵

CryptoKitties 的交易和以太坊上所有其他交易争同样的区块。每个区块有 gas 上限，矿工按出价挑交易，需求超过上限，出价低的就往后排[7]。配一次种至少两笔交易；Gen 0 拍卖、玩家之间的买卖、出租配种权，也都要各自发交易[1]。

冷却按区块号计时，网络再堵，怀孕也会按时到期；卡住的是接生那笔交易。发这笔交易的人先垫付 gas，再从合约领回繁殖费[1]。Jiang 和 Liu 写道，游戏的交易造成拥堵，gas 费随之上涨，游戏方因此调高了繁殖费[21]。团队 12 月 3 日的推文写道，多收的部分是为了激励矿工把接生交易打包上链[15]。

Citizen Hex 的联合创始人兼 CEO Benjamin Roberts 对 CNBC 说，有了 CryptoKitties，每个以太坊用户都突然承担起运行一个主流应用的计算开销，网络上的每一笔交易都受影响[20]。

调高 gas 上限的代价

gas 上限当时由矿工调整[7]。Alexey Akhunov 12 月 5 日写道，最近有人呼吁矿工调高 gas 上限；他同意另一些人的看法，除非能证明区块的传播时间可以大幅缩短，否则调高上限会降低挖矿的收益，矿工不太会接受[10]。Buterin 12 月 12 日在会议议程下写了一个近似关系：叔块率 ≈ k1 ÷ 出块间隔 + k2 × 每秒的 gas 用量，两项相加；他说眼下的问题出在第二项，他个人反对再拉长出块间隔[9]。叔块指几乎同时挖出、没能进入主链的有效区块。

经过

11 月 23 日至 12 月 1 日：上线

CNBC 写道，CryptoKitties 感恩节先向 200 名用户开放，11 月 28 日（周二）向公众开放[20]。IEEE Spectrum 写道，游戏在五天的封闭测试之后上线，打出的口号是“世界上第一款以太坊游戏”；Bladon 回忆，游戏一上线几乎马上就火了，“那段时间让人摸不着头脑”。据 nonfungible.com，上线当天售出约 1,500 只[22]。开发者告诉 Quartz，12 月 1 日游戏有 1,165 名玩家[15]。

12 月 2 日至 4 日：占比涨到三倍

12 月 2 日（周六），1 号猫 Genesis 售出。各家记的价格不一：TechCrunch 写约 246 ETH，约合 11.3 万美元[17]；BBC 和 Quartz 引用 Crypto Kitty Sales，写 117,712.12 美元[19][15]；CNBC 引用开发者 Niel de la Rouviere 的数据，写 114,481.59 美元[20]；Jiang 和 Liu 记为 247 ETH，他们写道，这条消息在网上迅速传开，引来大量关注[21]。

12 月 3 日，TechCrunch 写道，以太坊网络约 15% 的流量花在这款游戏上，第二名 EtherDelta 约占 8%；流量让游戏很难玩，买卖猫的交易要等很久。报道认为，一款还没走出科技圈的游戏就能拖慢网络，扩容是整个以太坊网络的隐忧[17]。团队当天发推，说因为网络拥堵，繁殖费从 0.001 ETH 调到 0.002 ETH，好让小猫按时出生，长期的办法很快会研究[15]。

12 月 4 日（周一），Quartz 引用 ETH Gas Station 的数据：CryptoKitties 合约成了以太坊上最忙的地址，占全部交易的 11.77%，是周六约 4% 的三倍，EtherDelta 占 8.85%[15]。Bloomberg 当天的报道同样引用 ETH Gas Station，写 11%；CoinDesk 的研究主管 Nolan Bauerle 在邮件里说，过去 24 小时以太坊上待确认的交易激增，主要来自 CryptoKitties[16]。CNBC 写道，团队当天又把繁殖费从 0.002 ETH（约 90 美分）调到 0.015 ETH（约 6.69 美元）[20]。Axiom Zen 的 Benny Giang 说，这天的活跃玩家有 6,600 名[15]。

12 月 5 日至 10 日：报道和高峰

BBC 12 月 5 日报道了这次拥堵。剑桥大学的 Garrick Hileman 对 BBC 说，有人担心一个无足轻重的游戏会挤掉更严肃的商业用途；在他看来，更大的问题是别的大玩家会去找以太坊的替代品，以太坊急需解决这个问题[19]。

CNBC 12 月 6 日报道，区块链项目 SophiaTX 因为拥堵，把代币发售推迟 48 小时，改到周四；Roberts 说，周三上午 CryptoKitties 约占以太坊网络的 13.5%[20]。

Jiang 和 Liu 按每天参与游戏的地址数划分阶段：12 月 2 日起大量玩家进入，热度迅速上升，12 月 10 日见顶[21]。IEEE Spectrum 引用 nonfungible.com，销量从上线当天的约 1,500 只涨到 12 月 10 日的 52,000 多只[22]。

52,000 只是哪一种数

IEEE Spectrum 没有说明 52,000 多只是 12 月 10 日当天的销量，还是到这天为止的累计[22]。CNBC 12 月 6 日引用 de la Rouviere 的数据，写累计售出 41,000 多只[20]；Bloomberg 12 月 4 日引用 Crypto Kitty Sales，写已售出 22,000 多只[16]。几个数字出自不同的统计，本页分开写，不互相推算。

12 月中旬以后：退潮

12 月 15 日的核心开发者会议上，区块仍然基本是满的[7]，游戏本身却已经在退潮。Jiang 和 Liu 写道，见顶以后热度急剧下降，2018 年初不到高峰的一成，1 月 15 日以后进入长期缓慢的下降[21]。IEEE Spectrum 写道，每天的销量 2017 年 12 月初见顶，1 月一路下滑，到 3 月平均不到 3,000[22]。

各方应对

Axiom Zen

团队手里能直接调的只有繁殖费。12 月 3 日从 0.001 ETH 调到 0.002 ETH，4 日调到 0.015 ETH[15][20]；Jiang 和 Liu 写道，后来又调回 0.008 ETH，此后还调过几次，最后稳定在 0.008 ETH[21]。Bladon 后来对 IEEE Spectrum 说，项目确实跌跌撞撞：停机过很多次，要应付很多从没用过区块链的人，还有一个 bug 漏掉了价值数万美元的以太币[22]。报道没有说是哪个 bug，本站也没有查到。

繁殖费一开始是多少

主网合约里 autoBirthFee 的初始值是 2 finney，即 0.002 ETH[1]，Jiang 和 Liu 也写发布时是 0.002 ETH[21]；团队 12 月 3 日的推文却说是从 0.001 ETH 调到 0.002 ETH[15]，赏金测试网版本的初始值也是 0.001 ETH[2]。COO 账户随时可以改这个值[1]，上线以后是否先调低过，本站没有查链上记录，两种说法并列。

矿工

第 30 次核心开发者会议的记录写道，gas 上限原来是 670 万，CryptoKitties 每个区块带来 100 万到 200 万 gas 的需求，推高了交易费；矿工把上限调高了一些，用量涨得更多，到会议时上限是 800 万，区块基本是满的[7]。维基百科写道，矿工因为 CryptoKitties 调高了 gas 上限，出处标的是 Quartz[30]；本站读到的 Quartz 存档里没有这句话[15]，gas 上限的数字用会议记录。

以太坊核心开发者

12 月 12 日，Buterin 在第 30 次会议的议程下留言，提议再做一轮调价。他说读取账户的操作码（BALANCE、EXTCODESIZE 等）和 SLOAD 仍是抗 DoS 的主要弱点，建议 SLOAD 调到 320，BALANCE 调到 800，EXTCODESIZE、CALL、DELEGATECALL 等调到 1,200；再用 EIP-168、169 的某种变体减缓状态的增长；向当前为空的账户发交易，多收 30,000 gas。他说自己完全支持无状态客户端，只要矿工保存状态，不改核心协议现在就能实现[9]。

12 月 15 日的第 30 次会议把这件事列为第二项议题，标题是“数字猫这个月造成了网络拥堵。喵。”会上介绍了 Akhunov 的无状态设计：矿工出块时附上一个“见证”块，里面有处理这个区块的全部交易所需的数据和 Merkle 证明，节点验证区块时不用再读磁盘，验证时间应当大幅缩短，gas 上限就能调高很多[7][10]。记录写道，Buterin 一直在推无状态的设计，因为这是分片研究的方向；实现它要大改 gas 价格等许多方面[7]。

有人担心读取变贵以后，区块会更快被填满。记录写道，Buterin 认为重新定价针对的是最坏的情况；一次攻击哪怕只占满区块 gas 上限的三分之一，也会把交易费推到 2 美元以上，几天里烧掉一百万美元。记录还写道，低成本的扩容办法有可能放进 Constantinople；状态通道是不改协议的链下扩容办法，应用开发者应当关注[7]。

2018 年 1 月 12 日的第 31 次会议上，有人问 Constantinople 会不会带来扩容上的改进。回答是不会：它可能包含 Casper 共识的第一步和一些账户抽象的 EIP，两者都不缓解扩容问题；眼下主要受限于数据库和处理速度，短期可以在客户端改进磁盘读写，长期需要分片[8]。

以太坊基金会

2018 年 1 月 2 日，Buterin 在以太坊基金会博客上写道，社区一直认为扩容可能是区块链应用走向大众之前最重要的技术难题。基金会把分片和二层协议看作互补的两条路，公布了两项资助计划，每笔资助 5 万到 100 万美元[12]。文章没有提到 CryptoKitties。

评论者

Bloomberg 写道，这款游戏是区块链上第一个成功的、和币无关的应用[16]。CNBC 写道，有人批评以太坊明显缺乏应付这种需求的规模；以太坊联合创始人 Joseph Lubin 回应说，以太坊拥有区块链平台里规模最大的开发者社区，尤其在这样的早期阶段，处在很好的位置，能够兑现它的潜力[20]。

这些比例为什么对不上

ETH Gas Station 按最近若干个区块的交易笔数统计，12 月 6 日的存档注明是最近 1,500 个区块[11]，按 15 秒一块约 6 小时（本站换算），数字随时在变：12 月 2 日约 4%，4 日 11.77%，6 日晚上 8.55%[15][11]。TechCrunch、BBC 和 VentureBeat 写的是“流量”，没有说明怎样算[17][19][25]。会议记录给的是 gas 用量，按 670 万的上限算是 15% 到 30%，按 800 万算是 12.5% 到 25%（本站换算）[7]。维基百科写约 25%，标注的出处是 CNBC 和 BBC，两篇原文分别写约 13.5% 和“一成以上”[30][20][19]。本站的规模数字用 11.77%，它的出处、日期和口径都明确[15]。

交易变慢、变贵

BBC 写道，流量越大，想让交易快点执行就越贵[19]。按 Etherscan 的数据，待确认的交易约为游戏上线时的六倍[15][19]。网络一直在出块，只是区块基本是满的[7]；受影响的是所有要上链的交易，SophiaTX 就因此推迟了代币发售[20]。

成交额

上线头一两周的成交额，各家引用的统计不同。Quartz 引用 Crypto Kitty Sales，六天成交约 270 万美元[15]；Bloomberg 12 月 4 日引用同一来源，售出 22,000 多只，共约 300 万美元，平均每只约 109 美元[16]；BBC 12 月 5 日估计约 450 万美元，中位价约 23.06 美元[19]；CNBC 12 月 6 日引用 de la Rouviere 的数据，写 670 万美元，中位价 25.04 美元[20]。成交额是玩家之间转手的 ETH 折成的美元，不是损失。

第一个走红的 NFT 应用

IEEE Spectrum 称它为第一款大型区块链游戏[22]。Jiang 和 Liu 统计了它此后约三年的数据：10 万个地址参与了约 500 万笔交易；84.6% 的地址在官方市场买过猫，64.9% 配过种[21]。直接调用核心合约转让猫只要付 gas，不交 3.75% 的抽成，于是出现了收费更低的第三方平台，例如抽成 2.5% 的 OpenSea[21]。2021 年的 NFT 热潮见Beeple 的 NFT 在佳士得拍出 6,935 万美元。

越繁殖越不稀有

Liu 对 IEEE Spectrum 说，一只猫的价格首先看基因决定的稀有度，其次看市场上有多少猫；人来得越多，猫也越多。繁殖让供给跟着需求一起涨，每只猫的稀有度很快被稀释，Bladon 也同意这个判断[22]。IEEE Spectrum 还写道，游戏越成功，玩家付的 gas 越多；过去三个月一只猫的中位价约 0.04 ETH，合 40 到 50 美元，常常不够付完成交易所需的 gas。它的判断是，gas 很可能最终让这款游戏玩不下去[22]。

后续

分拆和融资

2018 年 3 月 20 日，CryptoKitties 宣布融资 1,200 万美元，由 Andreessen Horowitz 和 Union Square Ventures 领投；TechCrunch 写道，游戏将从 Axiom Zen 分拆出来[23][24]。9 月 4 日，一只叫 Dragon 的猫以 600 ETH 成交，当时约合 17 万美元[22]。VentureBeat 10 月写道，玩家繁殖出的猫超过 100 万只，CryptoKitties 的合约上发生了超过 320 万笔交易[25]。11 月 1 日，开发方 Dapper Labs 宣布融资 1,500 万美元，Venrock 领投，GV 和 Samsung NEXT 参投[26]。

ERC-721 定稿

2018 年 1 月 24 日，William Entriken 以“EIP-721 Deed Standard”为题把标准提交进 EIPs 仓库；6 月 4 日进入为期两周的审议，6 月 22 日定稿[6]。定稿的作者是 Entriken、Shirley、Jacob Evans 和 Nastassia Sachs，依赖 ERC-165[5]。KittyCore 的 supportsInterface 只对 ERC-165 本身和 0x9a20483d 返回 true[1]；用定稿的接口号 0x80ac58cd 去问它，按这段代码会得到 false（本站据源码判断）。

Flow

2019 年 9 月，Dapper Labs 的 Alexander Hentschel 等人发表 Flow 的论文。论文开头写道，现有区块链架构的吞吐量限制有据可查，是它们普及的最主要障碍之一，引用的文献里有 BBC 那篇 CryptoKitties 拖慢以太坊的报道[27][19]。论文写道，以太坊用 gas 上限限制每个区块的计算量，吞吐量也因此受限[27]。

2020 年的 Flow Primer 写道，开发 CryptoKitties 和 Dapper 智能合约钱包这类应用的经验，让团队把许多改善开发体验的设计直接放进了协议层。Flow 把验证节点的工作拆成收集、共识、执行、验证四种角色，扩容不靠分片；Primer 举例说，在分片的链上用稳定币给一只 CryptoKitty 买一顶帽子，可能要 12 笔交易、7 个区块[28]。Dapper Labs 和 NBA 2020 年 10 月推出了 Top Shot[29]。

CryptoKitties 迁到 Flow 了吗

Engadget 2021 年 3 月写道，CryptoKitties 不久将从以太坊迁到 Flow[29]。本站没有找到迁移完成的公告。IEEE Spectrum 2022 年 8 月写到的 CryptoKitties 成交仍以 ether 计价、要付以太坊的 gas[22]。

以太坊的扩容路线

2018 年初，开发者把希望放在客户端的优化和分片上[8][12]。2020 年 10 月 2 日，Buterin 提出以 rollup 为中心的以太坊路线图；他写道，eth1 上的 gas 价格涨到新高，一些非金融的 dapp 被迫关停，另一些只能跑在测试网上[14]。2021 年 8 月，EIP-1559 改了交易费的算法，费用的水平没有因此下降，经过见EIP-1559 与 London 升级。2022 年 4 月 30 日，Yuga Labs 发售 Otherdeeds，以太坊的平均 gas 价格一度超过 450 美元，前一天约 50 美元[22]。

别的链也遇到过同样的事。2022 年 4 月 30 日，和 Otherdeeds 发售同一天，Solana 被 NFT 铸造机器人的交易压垮，停了约 7 小时，经过见Solana 多次全网停机。2023 年起，比特币上的 Ordinals 铭文占用区块空间，主张过滤的开发者说它挤占了支付交易，经过见Ordinals 铭文上线。

教训

给应用开发者
  • 用户的每个动作都是一笔要排队的交易。CryptoKitties 配一次种要两笔交易，网络一堵，接生交易就要靠更高的出价抢位置[1][15]。
  • 和 gas 价格挂钩的参数要能调。繁殖费写在合约的状态里，COO 账户随时能改，团队两天里调了两次，不用升级合约[1][20]。
  • 遍历全部数据的代码会随规模变慢、变贵。赏金期间就有人报告，列出一个人的猫要 O(m×n) 的时间；ERC-721 定稿引用这个 issue，提醒实现者不要写这样的循环[3][5]。
给协议开发者
  • 区块空间是全网共用的。一个应用走红，所有人的交易都要排队、加价；SophiaTX 因此推迟了代币发售[20]。
  • 调高上限有代价。按 Buterin 的近似关系，每秒处理的 gas 越多，叔块率越高[9]；Akhunov 认为，区块传播没有变快之前，矿工不会接受大幅调高上限[10]。
  • 扩容要花好几年。2018 年初的答案是改进客户端和分片[8]，2020 年转向以 rollup 为中心[14]；2022 年一次 NFT 发售仍能把平均 gas 价格推到 450 美元以上[22]。
给玩家和收藏者
  • 资产便宜、gas 贵的时候，交易不划算。2022 年一只猫的中位价约 0.04 ETH，常常不够付完成交易所需的 gas[22]。
  • 能无限繁殖的收藏品，稀有度会被稀释。人来得越多，猫也越多[22]。
  • 早期标准的实现不一定和定稿兼容。KittyCore 认的是草案的接口号 0x9a20483d，定稿是 0x80ac58cd[1][5]。
